WORK-011: work view ahbeh must use the graf index, not the raw keeper DAG walk

Now
OPEN

The work view computes every row's ahead/behind by set-differencing two full ancestor closures walked straight off the keeper, while shared/graf.js (GRAF-001) exists precisely to serve per-shard cached ahead/behind counts — and is wired into nothing but tests. Switch the view's ahbeh path to graf.open(shard).aheadBehind(...), keeping the keeper walk at most as a fallback. Investigated 2026-07-19 (Opus agent, be tip).

Input

Context

  • Counts today: registry().counts(repo, cur, tip) (views/work/work.js:139-148) set-differences two ancestorsOf closures; row emit sites work.js:240,250,256,260,511,531.
  • The closure walk: work.js:117-124 → dag.ancestors (shared/dag.js:99) → ancestorNodes → keeper.commitParents (shared/dag.js:53), BFS capped at WALK_CAP = 1<<16; dag.aheadBehind (shared/dag.js:227) walks the same way and is not even called.
  • Mitigation is memo-only: keeper opened once per (store,project) shardKey, closures cached per shardKey#sha (work.js:101-150) — still O(history) per distinct tip.
  • shared/graf.js — GRAF-001: per-shard cached ahead/behind COUNTS over wh128 runs, open(shard).aheadBehind(...), lazy *.graf.idx — required by nothing outside be/test/.

Goals

  • The work view's per-row ahbeh comes from the graf index: registry() opens graf once per shard and counts() delegates to graf.aheadBehind.
  • Big-fleet render cost drops from per-tip full-closure walks to indexed lookups; ~65 wts sharing a few shards (WORK-001 survey) is the target load.
  • Rendered numbers are unchanged — same counts as the closure diff on the same repo state.

Constraints

  • Behavior-only swap under counts(): the WORK-004 [+N]/[-N] button rendering and the view test layout stay untouched.
  • Decide the miss path: absent/stale *.graf.idx either falls back to the dag walk or triggers graf's own build — follow GRAF-001's contract, don't invent one.
  • Overlaps the unlanded WORK-001/003/004 work.js cuts; build on be tip, expect a weave.

WIP

Design decisions

  • idx-miss = graf's own contract: aheadBehind walks + caches on a miss; keeper closure diff kept only on a graf.open/aheadBehind throw.
  • registry() memos graf per shardKey beside keeper; counts() delegates graf.aheadBehind — numbers == the closure set-diff.
