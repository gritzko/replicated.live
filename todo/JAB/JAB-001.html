JAB-001 BIG: divorce be from jab (rename jabc→jab); be runs no JS

be currently forks the JS runtime jabc as its LAST dispatch fallback — an unknown bareword be <name> runs <wt>/bin/<name>.js (be_run_extension, JS-025). This couples a native CLI to a JS loader and keeps a doomed script duplicate in beagle/bin/. Divorce them: rename the binary jabc→jab, make jab a standalone runner (jab [path] args) with its own upward be/-scan resolution, and strip ALL JS from be. Canonical scripts already live in the separate be/ submodule (beagle-ext). Method: Issues.

Input

Context

  • beagle/beagle/BE.cli.c: be_run_extension (~4552–4627) forks jabc

    (sibling-resolved) on <wt>/bin/<name>.js; ext_name/ext_tail capture (~4913–4945); call site in the no-verb branch (~5123–5152).

  • beagle/js/main.cpp: entry runs the first positional via JABCRunFile

    (global eval). beagle/js/require.cpp: CommonJS require with node-style resolution (.js//index.js), no be/-scan.

  • Scripts duplicated: beagle/bin/*.js (doomed, deleted LATER) vs the

    journal-root be/ submodule (beagle-ext, complete: 8 verbs + lib/).

Goals

  • Rename the runtime binary jabc→jab; be and jab fully divorced.
  • jab [path] args: an explicit path (/abs, ./rel, ../up) runs the file

    directly; a bare name runs the require machine.

  • Require machine: scan UP for ./be ../be ../../be …, in each try

    <be>/<name> then <be>/<name>.js; ceiling $HOME/be (under $HOME) else /be.

  • be runs no JS: remove be_run_extension + plumbing + the JS-025 call site.

Constraints

  • Rename is the binary / user-facing name only — internal JABC* C++

    symbols stay.

  • beagle/bin/ is NOT deleted here; tests repoint to the be/ submodule.
  • Preserve direct-path global eval (CMake js/test/*.js use abs paths).
  • Repro-first (CLAUDE.md §17); full JABC* + bejs ctest suites green.

    __mainSpec and runs __main(__mainSpec).

    (upward be/-scan via io.cwd/io.getenv/io.stat); __main patches process.argv[1] to the resolved abspath so the be/*.js here idiom works.

  • BE.cli.c: the no-verb branch drops the extension probe and falls through

    to be_diagnose_unknown (typo diagnostic) then bro.
