JAB-011: io.readdir drops the first char of every entry under a trailing-slash root

Now
OPEN
Sev
HIGH

JABCReaddirRel (jab/io.cpp:315) strips rootlen + 1 bytes off each walked path, assuming the root never ends in /; JABCPath (io.cpp:26) copies the JS arg verbatim, so io.readdir(p + '/') returns mutilated names. Found in the 2026-07-24 jab/ house-cleaning review.

Input

Context

  • Live repro on a fixture dir: io.readdir(p) → ["alpha","sub/"], io.readdir(p+'/') → ["lpha","ub/"], recursive → ["lpha","ub/","ub/child"].
  • Any JS caller that composes the root from a URI dir path (which ends in /) hits this silently.

Goals

  • io.readdir returns identical entries for p and p+'/'.

Constraints

  • Repro-first: a test dir listed via both spellings asserts equality.
  • Fix the offset math or normalize in JABCPath — one place, not both.
