jab has no namespace for git/libdog utilities: every dog-family leaf installs FLAT on the abc object — abc._ulog_open, the _hash_* blob lanes, and the pack / hunk / cfold / index / pup / hit / weave / tok families — libdog riding the abc namespace. Ordered by gritzko 2026-08-11: a dog global namespace object; libdog bindings live there. This ticket is FIRST — STATUS-020's igno leaves land under dog.* from day one, never on abc.

Input

  • Rule: the namespace follows the C library a leaf wraps — leaves over abc/ headers stay on abc, leaves over dog/ (incl. dog/git/) move to dog.
  • Mixed cases to list explicitly in the inventory, not decided here: hash.hpp lanes run abc/HASHx machinery but the sha1/wh64/wh128 key types are dog's; cont/heap similar. Flag each with its includes and let gritzko rule on the split.
  • Both runtimes carry the change: jab (.hpp installs, JSC) and quickjab (.c installs, qjs) — same leaf names, same dog object.
  • Clean cut, no aliases: be/ call sites sweep to dog.* in the same change; the old abc.* names die.
