CI-002: HTTP GET → spell → hunks → HTML (web projector)

Now
OPEN

Serve Beagle views over HTTP by mapping the GET target into a context-verb-arg spell, executing it, and rendering the resulting HUNK stream as HTML with all links live. The pager's model verbatim on the web: URL bar = context, click = spell (URI, BRO-024 context law). No new resolution logic anywhere — be/core/resolve_hash.js and be/shared/spell.js stay the only resolvers.

Input

Context

The HUNK TLV already carries the full view model: rows, token tags, hidden U/O/F targets, banner URIs (be/view/bro.js, be/views/bro/pager.js). bro --plain (be/views/bro/bro.js) proves a spell can be executed headless and its hunks reproduced byte-exactly. mark/rss render the static site; live views (status, log, diff, tree, cat) have no web rendering at all.

Goals

  • GET /{verb}/{wtree}/{path}?{ref} → (ctx, verb, arg) → SPELL.compose → run → hunks → HTML page.
  • Verb absent → default by otype exactly like a pager row-click: tree→ls, blob→cat, commit→commit.
  • Every U token renders as <a href>, every read-only O spell as a link, every F key as its ticket page.
  • One theme: token tag → CSS class, class table generated from be/view/theme.js.

Constraints

  • The GET target is a URI: lex it with the native URI, compose with URI.make — no regex/string parsing (work §Things NOT TO DO).
  • ALL hash/path resolution via resolve_hash; context merge via SPELL.compose under the O-link rules (empty ctx leaves, absolute replaces, relative combines).
  • GET dispatches projector views ONLY (the view registry); mutation verbs render as plain text, never links.
  • Confinement is inherited: discover.resolve NAVESCAPE gates every path.

WIP

Design decisions

  • Fragment snag solves itself: #pin never reaches a server, but spec step 5.4 resolves ?hashlet as a detached commit — the renderer rewrites #sha links as ?sha; resolve_hash needs zero changes.
  • One bijective URL↔(ctx,verb,arg) codec module, used by BOTH the request mapper and the link renderer — the resolve_hash single-source doctrine at the web edge.
  • Serving starts CGI-style: frontend spawns jab html '<spell>' per request, matching the spawn-per-request wire model (stateless); a pol listener can come later without touching the renderer.
