jab <path>/main.js commit 57737c2c dies with require: cannot find 'jsrc/index/commit.js'. The entry script is given BY PATH, so QJAB-002 mode 2 applies and the only correct resolution is <script-dir>/index/commit.js — no jsrc/ element, no upward climb, no jsrc symlink to make it work. QJAB-002 landed that rule in quickjab/require.c; jab/require.cpp still carries the old jsrc-STACK climb, so the same command works under a current quickjab and fails under every jab.

Input

Context

VERIFIED by running the SAME command from ~/src/gitoxide on five binaries, arg commit 57737c2c against /home/gritzko/src/journal/work/LITE-009/main.js (which does require("index/commit.js")).

  • quickjab/build/bin/quickjab (Aug 13 11:14) — WORKS, prints the commit: mode 2 pins the script's dir as the require base.
  • jab/build-no-bundle/bin/jab (built Aug 13 16:32, fresh) — FAILS; ~/bin/jab (Aug 11) — FAILS, same message.
  • quickjab/build-w4 and build-dogsub — FAIL the same way; those binaries predate QJAB-002.
  • The failure is in the SOURCE, not stale binaries: jab/require.cpp (Aug 11 09:21) still has pinJsrcStack/resolveJsrc(spec, from) climbing for jsrc/ dirs; quickjab/require.c (Aug 13 11:08) has pinBase = bundle ?? scriptDir ?? one climb.
  • jab's __rebaseRequire only rebinds the TOP-LEVEL require's baseDir; a BAREWORD spec still routes to resolveJsrc, which never tries <script-dir>/<spec>.
  • The message itself spells the bug — it quotes 'jsrc/index/commit.js', a path nothing asked for.

Goals

A .js entry given by path resolves every bareword require against that script's own directory, under both runtimes.

  • jab <dir>/main.js <args> and quickjab <dir>/main.js <args> behave identically for require("index/commit.js") — both open <dir>/index/commit.js.
  • No jsrc element is ever spliced into a mode-2 spec, and no jsrc/ directory anywhere on disk changes the answer.
  • A miss reports the path it actually tried (<script-dir>/index/commit.js), so the message stops naming a phantom.
  • jab/require.cpp gets QJAB-002's three exclusive modes, the jsrc STACK dies there as it died in quickjab.

Constraints

  • This is a REQUIRE-layer fix; no lite/ or be/ change belongs in it.
  • A jsrc symlink beside the script is NOT the fix — it was tried as a workaround and removed.
  • QJAB-002's mode order is the spec: bundle wins over script dir wins over one climb, exclusive, no fallback chain.

WIP

Design decisions

  • quickjab needs no design work — require.c already implements the rule; the ticket's substance is jab's twin and a regression test that pins both.
  • Whether jab keeps a jsrc stack for its OWN entry modes is QJAB-002's call, already made: one base per process, no stack.
