A collection of low-severity binding defects found in the QJAB-005..010 security review — none a standalone memory-corruption hole, but each worth closing: ungated file-descriptor arguments, uncapped allocations that enable memory-pressure DoS, embedded-NUL path mismatches, an unbounded native recursion, a missing alignment guard, and two small latent hazards. Grouped here because each is a one- or two-line fix and none needs its own ticket. Split any item out if a fix grows.

Input

Context

  • These surfaced alongside the CRIT/HIGH tickets; they share the "untrusted JS value reaches a syscall/alloc with a weak or missing check" shape.
  • Most are by-design trade-offs (fds are plain Numbers) or DoS-only; listed so the decision to keep or gate each is explicit.

Goals

Each item is either fixed with a bounds/validation check or consciously accepted with a one-line note.

Constraints

  • Keep the leaf-only style; no new JS state.
  • Do not regress the fd-as-Number ergonomics unless the fix is cheap.

WIP

Design decisions

  • fd ownership tracking is likely out of scope (io.* is a general FS API); prefer a finiteness/range check on the cast over a full ownership table.

TODOs

  • io._ram: add the JABC_MAP_MAX ceiling io._mmap already has, so an oversized request fails with a plain word, not a late mmap/RangeError.
  • io.readdir recur path (io.c:233): bound recursion depth in the cb -> "recur" form; a deep attacker tree overflows the C stack today.
  • zip inflate sugar: cap total output (zip-bomb), stop the doubling grow-retry from allocating ~1 GiB before it throws.
  • arg.c JABCPath (arg.c:305) and dirc.c jdirc_str (dirc.c:30): reject an interior NUL — a "safe\0/x" string passes the length check but the OS truncates the C path (JS-view vs C-view mismatch).
  • tok.c JABCArgU8 (tok.c:20): n = cap - 1 underflows to SIZE_MAX at cap==0; guard cap ? cap-1 : 0 like the hunk.c twin (latent — only caller passes 64 today).
  • hunk.c _hunk_dogenize (hunk.c:85): add the srcn > TOK_OFF_MASK 16 MiB guard tok.c has (tok.c:50); over it, token offsets wrap and produce malformed hunks (caught later on drain, but silent).
  • index.c FINDGE_LEAF/SEEKRANGE_LEAF/COMPACT_LEAF (index.c:79, index.c:163): add the (uintptr_t & 7) alignment guard pack.c uses; an odd-byteOffset subarray gives misaligned wh128/u64 access (UB / SIGBUS on strict-alignment targets).
  • net.c/tty.c/fsw.c fd casts: at least reject non-finite/out-of-range before the syscall; decide whether fd ownership is worth tracking.
  • http.c head-length (http.c:42): last[1] can be NULL when a head has no version/reason/headers, making length garbage; assert version present on OK, or compute length defensively.

Blockers and bummers

  • fd ownership tracking may be deemed out of scope — record the decision here.
