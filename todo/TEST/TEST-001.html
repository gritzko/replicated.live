TEST-001 done: pin git default branch to master in the wire-parity harness

git 2.52 defaults init.defaultBranch to main, but the keeper/git wire-parity tests hardcode master; a bare origin then carries a dangling HEAD → refs/heads/main (only master is pushed), so the stock-git ORACLE clone checks out an empty tree while beagle correctly fetches ?master — the comparison then reports a spurious diff. Six tests fail (ROUNDtest, BEroundtrip, blobs-from-git, tag-blobs-from-keeper, clone-from-git, clone-from-keeper). Make the branch explicit. Method: Issues.

Input

Context

  • git --version = 2.52.0; a fresh git init → refs/heads/main. The harness builds master-tipped toys, so the oracle's HEAD-driven checkout is empty.
  • keeper/test/ROUND.c:286 did a plain git init $T (→ main) then git push origin master (:294) which pushes nothing → clone of an empty origin.
  • Shell tests build a bare origin with git init --quiet --bare (default HEAD main), push master, then git clone it: "warning: remote HEAD refers to nonexistent ref, unable to checkout" → empty git.list vs beagle's wt.list.
  • clone-from-keeper is special: keeper's canonical trunk is refs/heads/main (keeper/REFADV.c:67), so a master-only keeper mirror advertises a dangling HEAD→main; the git clone --upload-pack='keeper upload-pack' oracle then checks out nothing even after the origin pin.
  • Reproduce: ctest --test-dir beagle/build -R 'ROUNDtest|BEroundtrip|blobs-from-git|tag-blobs-from-keeper|clone-from-git|clone-from-keeper'.

Goals

  • All six tests green; the default branch is explicit, not environment-derived.
  • No product-code change; the harness stays master-themed by intent.

Constraints

  • Touch only test harness files; keep the toy repos on master.
  • The fix must work on both old (default master) and new (default main) git.

WIP

Design decisions

  • Pin git -c init.defaultBranch=master init … on EVERY bare-origin init (and ROUND.c's working seed), so the bare HEAD is refs/heads/master at init time.
  • clone-from-keeper: the oracle git clone gets --branch master so it checks out the branch explicitly and never relies on keeper's served HEAD symref.
