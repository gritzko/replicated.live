Twelve suites fail identically at every baseline anyone measured today: blob cat chatty http kv land list stage statnav status sync tree. The shared cause is a HARNESS artifact: fixtures run verbs from ~/tmp/lite-* scratch dirs, the unbundled runtime finds the JS by climbing cwd to the first jsrc/ link, and the suites mint that link too late or never — test/status/run.sh:241:ac links at leg 6 so legs 1..5 run verbless, test/blob/run.sh:128:7f mid-file, test/land never. The suites predate the unbundled runtime: a bundled quickjab carried its own packed jsrc, so the late link cost nothing then. Underneath sits a REAL tail: with jsrc present, test/sync still dies on uri.parse: malformed in commitOne (14 of 17) and test/blob's full-40-char object-id leg throws BLOBNONE — untriaged, masked inside the red set for who knows how long.

Input

Context

  • Three independent baseline sweeps today (pristine 165f655 and 5c1ac56 archives) fail check-for-check identically, so none of this is regression — it is standing debt.
  • The passing suites show the pattern to copy: ln -sf "$LITE" "$WORK/jsrc" in SETUP, before any verb runs.
  • A masked-red suite is worse than a missing one: today every real regression in those twelve would land unseen.

Goals

  • The jsrc link moves to each suite's setup (or the shared harness prologue, if one exists to own it) — one mechanical fix, twelve suites.
  • Every suite that then still fails gets TRIAGED: the failing leg, the actual error, and a verdict — stale fixture, environment leak (a fixture reading the real registry or HOME), or a REAL bug. A real bug becomes its OWN ticket text (report it, do not fix it here); a fixture/harness fault is fixed here.
  • Known tail to start from: sync's uri.parse: malformed in commitOne; blob's BLOBNONE on the full-oid leg.
  • The whole sweep ends green except suites whose failure is a reported REAL bug, each named in the report.

Constraints

  • Test-only changes: test/** may change, production code may NOT — a leg that fails against correct current behavior gets its expectation amended WITH the justification stated; a leg that fails on a real bug stays red and gets reported.
  • Fixtures must not read the real $HOME, registry, or any real repo — where one does, that is a bug of the suite, fix it with a fixture HOME as the registry-clean suites do.
  • No improvising around a failing command: report what actually breaks.
