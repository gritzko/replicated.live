Claude Code stores each session as an append-only JSONL file under ~/.claude/projects/<mangled-cwd>/. The chat verb renders those logs as StrictMark pages, one .mkd per session file, and is reentrant: a rerun appends only the turns the log grew by.

Input

Context

Session logs are JSONL, one row per event: {"type":"user"|"assistant",...,"message":{...}} plus non-conversation rows (mode, file-history-snapshot, sidechain rows). A project dir maps to its log dir by mangling the absolute path, non-alphanumerics to -, e.g. /home/gritzko/src/journal → ~/.claude/projects/-home-gritzko-src-journal/.

Goals

  • jab chat [dir] [outdir], both optional, both default .; dir is a project dir, its log dir derived by path mangling.
  • Convert every *.jsonl in the log dir to <outdir>/<basename>.mkd, strict 1:1 by basename.
  • Page opens # Session: <date> <time> <user> from the first conversation row's timestamp; no other chrome.
  • User turns are blockquotes (> prefix on every line); Claude text stays plain and verbatim — Claude already emits markdown, keep it.
  • Tool invocations are 4-backtick fences, one line per call — tool name + essential arg (command/file_path-style key, else compact capped input) — tool RESULTS are dropped entirely.
  • Skipped: slash-command noise (<local-command-caveat>, <command-name> etc), system reminders, sidechains, thinking, tool results, all non-conversation rows. No XML snippets in the output, ever.
  • Reentrant: the last line is a hidden ref def [log]: file:/<abs jsonl path> "<consumed bytes>". On rerun: size == bytes → skip; size > bytes → drop the trailing ref def, render only the new rows, append, restamp; size < bytes (rewritten log) → regenerate whole file.

Constraints

  • JS verb under verbs/chat/ in ///be, layout modeled on an existing verb (verbs/rss/rss.js).
  • No manual URI parsing anywhere; args are filesystem dirs, handled like other verbs' path args.
  • Tests follow the repo's existing test layout; sh tests must run under dash, no $'\t'.
  • Output is self-describing; no sidecar state files.

WIP

Design decisions

  • Format v2 ruled 2026-08-13: quote/plain/fence turn shapes, no json-in-markdown, no XML, no tool output; v1 ## headers + json fences reworked in place.
  • Trailing [log]: ref def over a sidecar or meta pair: hidden in render, carries provenance (which jsonl) plus the consumed byte count, survives copies; overwritten on each extend.
  • A turn is ONE jsonl row, never a merged same-speaker run: keeps an append byte-identical to a from-scratch render (no turn straddles the boundary); the append test asserts it.
  • thinking blocks dropped; a v2 invocation line is tool name + primary string field (command, file_path, …; description beats prompt), else compact input JSON capped ~200 chars.
  • <task-notification> rows skipped too — not enumerated in Goals, but the no-XML rule is blanket.
  • The Session header stamps before the first RENDERED row, not at file creation — keeps append byte-identical when a log opens with noise only.
  • $CLAUDE_CONFIG_DIR honoured (Claude Code's own env var) — the hook that lets tests avoid the real ~/.claude.
  • Sanitizer (ruled 2026-08-13, overrides the verbatim blocker): depth-0 header / ref def / meta pair / never-closed fence run in Claude prose takes one leading \ — block layer sees off-grammar prose, inline \c escape keeps it reading as written; balanced fences and their bodies stay byte-verbatim.
  • Every created/appended/regenerated page reports one chat: wrote <path> line (up-to-date pages silent) via io.log, the verbs' fd-2 message stream.
