Design decisions

  • RULING (user 2026-06-26): the diff is ALWAYS commit.tree vs parent[0].tree (the FIRST parent) — merges included (git --first-parent; consistent with beagle's first-parent log spine, LOG-001). No merge special-case, no skip.
  • DRIVE: call the diff VIEW handler (../diff/diff.js) with a PINNED views spec {mode:range, fromSha:parent0, toSha:sha} — bypasses dead ctx.views.
  • ATTACH: PLAIN folds the diff TEXT (out.chunk) into the ONE metadata record (HUNK plain adds a sep PER record; native has none mid-stream). COLOR/TLV feed the diff's own records after metadata (no sep; native tlv = 2 hunks).
  • ROOT (0 parents): SKIP (no base; native's root diff is wt-driven/odd — skip is simpler). All others (incl. merges) diff vs parent0.
