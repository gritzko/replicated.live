URI-006: transport cleanup — hostless be: = local keeper; file: is worktree-only

Now
DONE

Beagle conflates two roles in file:: a local worktree SOURCE and the host-less LOCAL keeper WIRE (clone/fetch/push). be: is the keeper protocol but is ssh-gated (needs a host), so file:// is currently the ONLY local keeper edge — which blocked making file: worktree-only (URI-005 v1/v2 forks). Decision (user 2026-06-22): split the roles. Hostless be: runs the keeper LOCALLY (same protocol, no ssh pipe — ssh is only the remote transport); file: becomes WORKTREE-ONLY (always a shared-store worktree, never an own-store clone), slash-agnostic. Net: be: = keeper transport (local hostless OR ssh remote); file: = local worktree attach. Umbrella/epic. Method: Issues.

Input

Context

  • file: running keeper is the same protocol as be: minus the ssh pipe (user) — so a host-less be: is the natural local keeper transport, and file: need not carry the wire role at all.
  • Today file://<dir> makes an own-store clone over the local keeper wire; ~20 tests use it for clone-and-push-back: be-post-32/38, be-patch-33, be-get-30, head/19-25, post/35-48 (verified by the v2 worker). These migrate to hostless be:.
  • Keeper transport seam: keeper/KEEP.exe.c:1298 treats be/file as the keeper protocol; keeper_remote_uri, keep_post_is_git_wire, keeper_post special-case host-less file://. The GET-012 slash-count signal + be-get-29 encode file:=clone.

Goals

  • Hostless be: (e.g. be:/abs/.be?/proj) runs keeper locally (no ssh): clone / fetch / push exactly as be://host does over ssh.
  • file: is worktree-only: be get file: always attaches/updates a shared-store worktree (no own store), slash-agnostic; the file: clone/push path is removed.
  • Migrate the ~20 file:// clone-and-push-back tests onto hostless be:.

Constraints

  • NEVER hand-rolled parsing — ragel grammar + dog dispatch (CLAUDE, ABC).
  • Land URI-005 (the trailing-slash bug) first — it is independent and narrow.
  • Don't regress be://host (ssh remote) or ssh://. Core transport — adversarial tests, repro-first per stage.
