Goals

Board and todo TOPIC rows grow, in order: sev bullet, key, wt link, counts, fade; family children nest under their parent. Composes with the /todo/TODO/TODO-002 badge and the BE-040 [done] button, forks neither.

  • Sev bullet FIRST in the row: one colored ● off Sev: (CRIT red, HIGH orange, MED plain, LOW dim); open/closed state in the same glyph (closed tickets, when a TODO-004 filter shows them, render hollow ○).
  • Wt link: a matching work/<KEY>* wt puts a visible [»] slot after the key, minting status //KEY — the symmetric twin of work's [?]; no wt → the slot ┄-fills (fixed columns, the work R2 discipline).
  • Ahbeh + dirty counts off the wt: [+N][-N] via work's registry/graf cache, plus changed/new/deleted file counts (~N +N -N) off the wt status; zero sides show nothing, two-digit clamp — the work ahbehSpans conventions.
  • Age fade: the row's fade rides the ticket's last-touch time from /todo/BRO/BRO-044 mtime.idx; pager-only leading #rrggbb O token, fadeHex reused as-is.
  • Family nesting: a ticket whose Sub: names a listed OPEN parent indents under it, dotted rails (├┄┄, work's tracker-run look); a parent-less or closed-parent Sub: renders flat.

Constraints

  • Sev:/Now:/Sub: come off the ONE TODO-001 read (a pageMeta head-scan of Key: value lines) or the TODO-003 index — never a second open per ticket.
  • Counts cost keepers: open per shard ONCE (work's registry()), and only for tickets that HAVE a wt; the no-wt board must stay index-fast.
  • Dirty counts come from the status machinery, no parallel differ (reuse-libdog); if a wt is unreadable the slot ┄-fills, no error row.
  • Plain mode stays chrome-free: bullets, links, buttons and fade are pager-only; the sev ORDER still applies to both.
  • Existing todo goldens keep passing modulo the added spans; the repro test pins the row layout, the wt-match rule and the nesting rule.
