The header regained the legacy [DONE] mark that the TODO-005 ruling retired in favour of the Now: pair; and instead of rewriting the existing Now: OPEN, the verb INSERTED a second Now: DONE at column 0 — outside the four-space meta block, so it is not even the pair the board reads. Input

Context

The page on disk after done ran, todo/BRO/BRO-046/README.mkd:1-5:

  • # BRO-046 [DONE]: idle pager leaks 19 ULOG mmaps/sec … — the legacy mark is back in the title.
  • Now: DONE at column 0 on line 2, then a blank, then the real block at four spaces still carrying Now: OPEN and Sev: CRIT.
  • flipHeader (verbs/done/done.js:70-91) writes the mark deliberately — done.js:4 calls it "the legacy DONE mark still flips", the BE-040 convention from before the pair existed. It is now obsolete, not merely redundant: the two can disagree, and this page proves it.
  • setNow (done.js:124-132) rewrites a found Now pair IN PLACE at that pair's own indent, and only splices a new line when the block carries none. On this page it should have rewritten the existing pair.
  • The block grammar does NOT end at a blank line (shared/metaidx.js:277-285): a blank line is skipped, the ticket header is skipped once, and only a non-blank non-pair line ends the block. So Now: OPEN sitting under a blank line IS inside the block, and metaBlock should have returned it.
  • Root cause is therefore NOT established from reading alone — on the grammar as written, the rewrite branch should have been taken. The pre-done text is not recoverable: the page is open in vim with unsaved changes (swap 15:56 against a file saved 11:50), so the on-disk state may not be purely the verb's output. The repro decides this, not the reading above.

Goals

done leaves exactly ONE status statement on a page: the Now: pair, inside the block, at the block's own indent.

  • Red-first repro: a fixture page shaped like BRO-046 — header, blank line, four-space block whose first pair is Now: OPEN. done must rewrite that pair and add no line. Red today.
  • Neither done nor dont writes the legacy [DONE]/[DONT] title mark any more.
  • A page carrying no Now: pair still gains one, at the four-space house indent.
  • dont rides the same _run (done.js:291) and must land identically — fix once, assert twice.

Constraints

The pair grammar stays in ONE place.

  • Read the block off shared/metaidx.js metaBlock, never a second line regex — that is the TODO-005 ruling and the reason setNow takes line+indent from the matcher.
  • Pages ALREADY carrying [DONE] in the header are NOT rewritten here; sweeping the ~40 closed pages is separate (BE-059 territory). This ticket stops the verb from writing new ones.
  • Do not widen into BE-040's delist half, nor the board render (TODO-004).
  • Clone ///be/ per work; on any clone failure stop and report, no improvised fallback.
  • Worktree only — no put/post in the main tree, and no commit without an explicit order.
