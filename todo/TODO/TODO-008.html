TODO-008: ticket-valued meta clicks navigate to that ticket

Now: OPEN Sev: LOW Rep: ///be/ On1: TODO-004 Ask: gritzko

Nit (gritzko, 2026-08-04): when a meta pair's value is a ticket code (On1: ABC-020, See: BE-050, Dup:, Sub: …), clicking that value must NAVIGATE to the ticket's page, not toggle a filter. TODO-004 made both halves clickable, but a value click replaces that key's filter in the arg line — and for ticket-valued keys filtering is presence-only, so the click is dead weight exactly where a jump is wanted.

Input

Context

  • TODO-004 click model: the spell carries the WHOLE arg line and a value click swaps that key's Key:Value filter in it.
  • TODO-004 already lexes [A-Z]+-[0-9]+ as the ticket-id class in the :todo arg grammar; the same class decides here.
  • Registered ticket-valued keys per todo: On1: On2: … See: Dup: Sub:; values are one ticket code per slot.

Goals

  • A meta VALUE that lexes as a ticket id clicks to :todo TKT-123 — same landing as clicking that ticket's board row.
  • The KEY half keeps its present behavior (presence filter).
  • Applies wherever meta pairs render: the ticket-view meta block and any board-row inline values.

Constraints

  • The value's lexical class alone decides — no key registry; an unknown key with a ticket-shaped value navigates too.
  • Click spell stays the whole-line BRO-025 shape; the pager stays arg-blind, resolution in the verb (Nav design law).
  • A dangling target (no such ticket) gets the :todo verb's existing plain-words error, nothing new.
  • Repro through the real UI path: a pty click on a rendered ticket-valued pair must FLIP from today's filter/no-op to landing on the ticket page; TLV-only probes do not count.

WIP

Design decisions

  • ONE navSpell(v): shape(v)==="key" → todo v, else null.
  • Both render sites call it — the page meta block (pageLinks) and the board's inline [value] bracket (todoFilter).
  • NO page-file probe at render: the class alone decides, and a dangling code lands on todo's own miss line.
  • The KEY half is untouched — still Key:* on the whole line.
