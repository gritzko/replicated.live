A tty be todo render loads the ignore matcher 355 times and parses .gitmodules 310 times for 149 classified repos. Measured attribution (2026-08-05, main tree, 137 wts / 863 tickets): cache.js's arm() does 204 ignore loads, classifyMerge redoes 151 of them for the SAME roots microseconds later; recurse.walk parses 159 .gitmodules, classifyMerge parses the same files 151 times over. This is a redundant CALL CHAIN, not a missing cache: TODO-006 already publishes the arming walk (S.walk) but not the matcher that produced it. Cure = hand the work down, don't re-read.

Input

Context

Profiled through the pty (the real UI path), warm first paint 2.6-2.9 s, 5.6 s cold; classifyMerge is 149 calls (78 wts + 71 mounted subs) and 1.9 s of a 3.3 s render.

  • cache.js:212 arm(wt) loads the matcher at :216, walks with it, then publishes ONLY the walk: S.walk = {wt, rev, w} (:229).
  • classify.js:253 parses <wt>/.gitmodules and :254 reloads the matcher for the same root the arming walk just used.
  • recurse.js:77 gitmodulesOrder(repo.wt) parses that same file a second time; todo.js:584 foldCounts then :585 foldSubs run the two back to back, per repo.
  • ignore.js:195 load() climbs to the project root: todo/.gitignore and /.gitignore are re-read 43x each (one per topic anchor).
  • ignore.js:171 declaredSubOf has its own .gitmodules reader (STATUS-018), mapping journal/.gitmodules 149x; parseText runs 478 times per render (250 under the arm climb, 228 under classifyMerge).
  • Syscall totals per render: io.mmap 1507 calls / 436 distinct paths (1071 repeat maps), .gitmodules mapped 312x, io.lstat 54644 / 40647 distinct, io.stat 42979 / 39981, readAll 14740.
  • NOT in scope, separate leads: the 14740 per-file content reads in classify.js:521 wtEqBase, and readTreeRecursive running 149 times over only 86 distinct tree shas (the clones share a trunk tip).

Goals

  • Each repo's .gitmodules is parsed once per render, each anchor's ignore matcher loaded once — the duplicate legs (151 + 151) die.
  • Shared parent files (/.gitignore, todo/.gitignore, the project .gitmodules) are read once per render, not once per anchor.
  • Emitted board bytes byte-identical before/after; no verb changes.

Constraints

  • No second cache mechanism: the rev tree (cache.js, STATUS-019) is the only change witness; a memo carries a rev or it does not exist.
  • With no live watcher every lookup must MISS and recompute — a mutation verb never starts the watcher (loop.js:499), so its behaviour must stay byte-identical by construction.
  • ignore.js must not require core/discover.js (STATUS-018) and nothing may re-close the cycle CODE-030 cut (classify.js:62).
  • Callers that pass no witness (stage.js:87, get.js:1092, tests) keep today's path unmemoised.

WIP

Design decisions

Two legs. Leg A deletes calls and needs no new state; Leg B memoises only the shared parent files. Leg A alone kills 302 of the 665 duplicate calls.

  • Leg A1: widen the TODO-006 slot to carry what produced the walk — S.walk = {wt, rev, w, ig} (cache.js:229), plus a takeArm(wt) twin of takeWalk (:235) with the identical live/wt/rev guard.
  • Leg A2: classify.js:253-254 takes that slot when it is there and threads the walk into wtScan instead of re-taking it; a null slot falls back to today's load, so no-watcher runs are unchanged.
  • Leg A3: classifyMerge keeps the parsed sub-path array and returns it; recurse.walk accepts opts.subs (recurse.js:74-77); todo.js threads it from foldCounts into foldSubs (todo.js:584-585).
  • Leg B: memoise the PARSED FILE per its own dir, keyed by the rev of that dir, so 137 wts sharing journal/.gitignore share one entry — never keyed per anchor, or the sharing is lost.
  • The witness query must arm ONE level only (a full rev() re-enters arm → ignore.load → recursion) and must drain the queue first, so a write from a pager mutation spell is seen before the memo answers.
  • declaredSubOf (ignore.js:167) drops its private reader and shares the per-dir .gitmodules entry; ignore.js stays free of discover.js.
  • Storage side (module-level maps vs one fs-mirror value tree hanging off the rev tree) is still open — gritzko's tree proposal covers it and supersedes Leg B if it lands; Leg A is orthogonal either way.
