Context

In the meta root, jab status //ABC-008 then a typed :diff diffs the META, not ABC-008 — the address-bar composer's context fell back to navCwd(cwd).

  • loop.cli's universal pager edge (_openPager, core/loop.js) hands the Pager ONLY hunks; the run's resolved nav scope (authorityRepo → authority/ctxDir) is dropped.
  • pager._composeCall reads (view.uri) || be.navCwd(); the INITIAL view (setHunks at launch) has no tracked uri, and the design law forbids scavenging hunks0's banner — so the CLI arg's //WT never enters the context.
  • :spell-navigated views DO track context (_driveApply sets view.uri = c.context) — only the CLI-launched first view leaks.

Goals

  • RULING 2026-07-10: the initial pager context derives from cwd AND the argument — AT LEAST the worktree; the worktree only ever switches explicitly.
  • jab status //ABC-008 + :diff → diff scoped to //ABC-008.

Constraints

  • context rides Pager opts (the explicit thread), never a hunk-row scavenge (Nav law); minimal diff in core/loop.js + views/bro/pager.js.

WIP

Design decisions

  • launch context = be.navCwd(ctxDir): ctxDir already encodes cwd AND the arg (an explicit //X pins the tree root, BE-039 sub re-anchor included; a plain run pins the invocation cwd — the pager's old default, so no behavior change without an authority arg).
  • Pager gains opts.context; _composeCall falls back view.uri → opts.context → navCwd().
