Context

Reported by gritzko 2026-07-09: in the pager, jab diff then spell :./test → "no hunks" (bar diff //journal/be/test, SRC_ROOT set) and, SRC_ROOT unset, bar diff ///be/test (correct) but the view re-runs the BARE diff (first hunk core/discover.js) — the context path is not respected. Three causes traced:

  • CONFIRMED by CLI repro: jab diff test scopes, jab diff ./test is EMPTY — parseDiffArg (views/diff/diff.js:434) keeps u.path verbatim and diffWtTree's prefix filter (:267) compares ./test/ against classifier rows test/…; the ./ is never collapsed (only wtpath's lstat normalizes, not the prefix).
  • BE-031 S2 aftershock: navCwd composes the META as // (empty authority), but resolve() (discover.js:280) and wtdir() treat host ""/"." as the LAUNCH tree find(io.cwd()).wt — the NEAREST anchor, i.e. the be/ SUBMODULE when launched there — so ///be/test resolves <be>/be/test (absent), not <meta>/be/test.
  • authorityRepo (core/loop.js): an empty-host arg whose wtdir misses skips the NAVNONE throw (host !== "" guard) and continues — the raw ///be/test reaches the verb, degrading to a bare whole-wt diff.

Goals

  • jab diff ./test (CLI) and :./test (pager, both SRC_ROOT states) scope the diff to test/.
  • //-authority URIs resolve against ONE tree definition, matching what navCwd composes.

Constraints

  • Repro-first: a RED test per leg (new test cases allowed; existing tests untouched).
  • Confinement invariants stay (resolveInTree NAVESCAPE paths byte-identical).
  • The pager stays arg-blind (Nav): fixes land in the verb/resolver, not in spell pre-merging.

WIP

Design decisions

  • ./-collapse belongs where the path enters the verb (parseDiffArg or a shared normalizer), so the classifier prefix compare sees canonical repo-relative paths; sibling views (cat/ls/why/log) likely share the pattern — sweep.
  • Empty-host semantics: ""/"." should mean topWt(find(cwd).wt) — the tree navCwd names // — in resolve()/wtdir(); the launch-tree reading predates BE-031 S2 making // the meta's everyday name.
  • authorityRepo: an empty-host wtdir MISS must be loud (NAVNONE), never a silent verbatim pass-through.
