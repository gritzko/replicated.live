BE-055 evidence: JS-side .be kind tests, creators, row-0 readers

Opus sweep over be/ (beagle-ext) and jab/ bindings, 2026-07-24. Every path that tests .be's kind (dir vs file), assumes dir⇒store / file⇒flat wt, creates .be, or parses the row-0 store reference.

The core anchor test — be/core/resolve_hash.js

  • L52–55 storeOf(anchor): composes the shard root as <x>/.be; a flat wt's shard-less .be/ still composes as a store root.
  • L61–70 anchors(dir): THE kind test — kind==="dir" ⇒ "own store in .be/", return true; kind==="reg" ⇒ parse row-0 of the file, anchor iff a first-row URI exists. A flat .be/ dir is adopted as own-store and never reaches the redirect branch.
  • L67: ulog.each(be,…) row-0 parse of the .be FILE.
  • L308 comment: shard==="" ⇒ the .be dir holds packs directly.

Discovery / anchor reader — be/core/discover.js, be/shared/wtlog.js

  • discover.js L85–91 row0Row(bePath): wtlog row-0 store-anchor parse. L33–34 the BE/WTLOG literals.
  • discover.js L101–131 resolveAnchor(wt): the kind fork — reg ⇒ store+project from the row-0 redirect (L106–116); else ⇒ bePath=<wt>/.be/wtlog, storePath=wt (L116–128). A flat .be/ dir wrongly gets storePath=wt here.
  • discover.js L49–61 repoFromBe, L72–81 projectFromPath: split on the /.be/ literal (row-0 pivot).
  • wtlog.js L67–79 open(be): drains be.bePath (correctness depends on resolveAnchor's member-file choice). L223–233 anchor()/repo(): return row-0 as the store anchor.

Store open / shard enumeration — be/shared/store.js

  • L129–158 shardDir(storePath, project): readdir(<store>/.be) enumerates subdirs as project shards; a flat .be/ (no shards) scans to a bogus/empty shard. L166–178 packs() readdir for .keeper files. L649–679 createShard/set/tombstone/ensureShard mkdir + seed refs under the store .be.

Wire / serve — wire.js, serve.js, submount.js

  • wire.js L43–107 classify + L57–59 servePath; L512–516 serveReader flat-store retry (GIT-020).
  • serve.js L92–106 serveStore: .be path kind==="reg" ⇒ WORKTREE (resolve store via discover.treeAt); else open as store/.be-dir/shard — the same reg⇒wt / dir⇒store fork.
  • submount.js L221–231 resolveLocalStore: kind==="reg" ⇒ worktree source, follow row-0 redirect; L143–146 a path ending .be marks a store source; L268/365–367 sibling shards land under the parent's .be/.
  • submount.js L270/333/375–383 mount: WRITES the sub anchor <sub>/.be as a FILE (redirect+track rows); L399 rollback via io.unlink — assumes a file. L50–59 currentSubPin reads the anchor FILE's rows for the #sha pin.

GET — be/verbs/get/get.js (the .be creators)

  • L119–120/165–189 resolveLocalSource: kind!=="reg" ⇒ store as-is; "reg" ⇒ worktree, row-0 redirect (L177–185).
  • L144–153 oldTipOf(bePath): reads .be file rows for #sha.
  • L205–217 seedLocal: CREATES the flat-wt .be FILE (redirect + tip row) — the site the dir-ification replaces.
  • L227–277 seedRemote: CREATES the own-store shape — mkdir .be/, ingest.clone shard, write .be/wtlog.
  • L304–310 isRemoteSeed: path ends .be ⇒ remote store seed. L362–429 handleWtSeed writes the .be file for //X clones.
  • L985–990 sub UNMOUNT: any .be present ⇒ io.rmdir(full,true) of the whole sub. L1499 default bePath=<wt>/.be.
