BE-055 evidence: native .be kind tests, creators, store scans

Opus sweep over beagle/ (keeper, dog, graf, sniff, spot, mark, woof, bro, beagle/), 2026-07-24. Sites where .be-dir ⇒ full store / .be-file ⇒ flat wt is assumed, plus creators and store-side scans.

dog/HOME.c — the two central classifiers (highest impact)

  • L938–964 home_walk_up: the discovery scan-up. REG ⇒ secondary wt; DIR ⇒ wt iff .be/wtlog is reg OR shield-like (≤1 subdir). A flat .be/ dir anchors as store==wt via the wtlog branch.
  • L637–708 home_anchor_resolve: sets h->root. REG (L651) ⇒ row-0 redirect to the real store; DIR (L708) ⇒ h->root=h->wt. THE core break — a flat wt's store is elsewhere.
  • L761–816 home_be_subdirs/home_dir_shieldlike/ home_single_shard: .be/ subdir census ⇒ shield vs multi- project store; a flat .be/ (files only) reads shield-like — passes, but for the wrong reason.
  • L826–851 home_shard_title / L865–920 home_resolve_project_dir: iterate .be/<shard>/refs row-0 titles (harmless-but-wasteful on a flat dir).
  • L141–157 home_ensure_markers: rw bootstrap CREATES .be/ dir + wtlog. L160–199 HOMEBeDir/HOMEMakeBeDir/ HOMEProjectExists: path composers (kind test on the SHARD).
  • L562–587 home_peek_repo_uri: mmaps a given path as a FILE (secondary .be or primary .be/wtlog) — caller chooses.

sniff/ — wtlog dispatch, submounts, dirty scan

  • SNIFF.c L73–90 SNIFFWtlogPath: REG ⇒ the .be file IS the wtlog; else <wt>/.be/wtlog. Yields the right FILE for a flat dir — but the store root (HOME) is what breaks upstream.
  • SNIFF.c L43–51/56–71: FILEStat(<store>/.be/<branch>) DIR probes (store-side). L128–158 sniff_write_repo_row: CREATES <wt>/.be/<project>/ shard + colocated row-0 anchor. L174–190 pre-mkdir <wt>/.be/ on fresh primary.
  • AT.c L932–940 at_dirty_scan_cb: prunes a subdir iff its .be is REG ("beagle's own sub-mount shape (a regular .be file)") — a flat-dir sub is NOT pruned, its files scan into the parent. DIRECT break.
  • SUBS.c L1120–1147 SNIFFSubIsMount: mount ⇔ .be is REG — a flat-dir sub reports NOT-a-mount. DIRECT break.
  • SUBS.c L332–337 subs_path_is_be_store: FILEisdir(<p>/.be) ⇒ "a beagle store" — a flat wt classifies as a store source.
  • SUBS.c L114–117 .be name refusal; L265–297/786–831 seed refs+wtlog under sub-store dirs (creators, store-side).
  • PUT.c L620–629 put_is_sub_add_candidate: .be present (ANY kind) ⇒ candidate — kind-agnostic, tolerant.

keeper/RECV.c — colocated-wt advance gate

  • L487–495 RECVCaptureWtPath: S_ISREG(<wt>/.be/wtlog) ⇒ primary wt with store HERE ("a dir there means a bare store"); triggers the colocated be get ? advance. A flat .be/ dir passes the gate with a REMOTE store — wrong advance. (Same-dir invariant at L452–462/476–485.)

beagle/BE.cli.c — attach / clone / post classify

  • L788–808 source classify: FILEisdir(<src>/.be) ⇒ primary store; REG ⇒ secondary wt; basename .be ⇒ store. Flat-dir source reads as a primary store.
  • L824–849 cwd gate: .be dir in cwd ⇒ "clone-destination store, defer to keeper (NOT a worktree)"; REG ⇒ existing wt switch. Flat-dir cwd treated as a bare clone destination.
  • L906–929: row-0 read — primary from .be/wtlog, secondary from the .be FILE.
  • L2541–2556 BEEnsureProjectRepo: REG ⇒ secondary, skip shard init — flat dir falls through to shard creation. L2599–2643 shard-dup guard + CREATES <cwd>/.be/<proj>/ + .be/wtlog.
  • L2797–2879 be_sub_shard_setup: seeds the sub shard, then CREATES <cwd>/.be as a regular FILE (L2876) with the secondary row-0 anchor — the current flat-wt writer that the planned change replaces.
  • L3378–3388 bepost_wt_project: DIR ⇒ push wtlog, else mmap the .be file directly.

beagle/SUBS.c — unmount

  • L510–524 BEGetSubUnmount: FILEUnLink(<sub>/.be) — assumes a FILE; a flat-sub .be/ dir is not removed (needs rm -r). DIRECT break for the drop path.
