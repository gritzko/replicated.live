Design decisions

A deletion mints no rev of its own (index.js's ZERO40 skip), so deleterOf — which walks the path's OWN later revs — cannot name the commit that removed the FILE; it still names the one that took the LINE. gonerOf answers the file case: HEAD's ancestry newest first, bounded by the same DELETER_SCAN, the oldest commit still missing the path. The seat carries the anchored BYTES, since the worktree has none: door.js seatOf passes them through and view/see.js quotes them in place of its worktree read. The index leg fires only when HEAD's tree spells the path NOWHERE, so the live-file leg and the foreign fan-out keep their goldens untouched.
