Design decisions

  • The gate is read where the lex is: toks stays null when both text rounds are up, and linkRows/symRowsOf are the only readers, so nothing downstream sees the null.
  • The tick counts EVERY blob of the list, binary and over-cap ones included, since the list is what the round walks.
  • prog.done() closes the line the ticks opened, as the commit walk does at index/index.js:1162:Wt.
  • The repro is in test/lindex/rows.js: tri.laneOf stubbed to null builds the pre-BEE-071 index (LINK/SYM marked, no tri mark), then a counting hk.parse and a counting idx.progress measure the TRI-only round — 5 lexes and 0 ticks before, 0 lexes and 6 ticks after.
