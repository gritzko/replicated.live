BRO-030: unified quad status reporter (track·base·patch·wt vs root)

Now
DONE

Input

Context

File status and divergence reporting is a per-verb zoo: status prints /wiki/Dirty nouns, PATCH prints applied/merged/mod/conflict (/wiki/PATCH §Reporting), GET/POST print their own rows, and ahead/behind is a separate post/miss listing. The unified model is specced in /wiki/Status: per path a quad of relations . X + ↑ — columns track/base/patch/wt, each vs root = LCA(track, base) — colored blue/green/yellow/orange; bold = staged, red = conflicted; commit ahead/behind uses the same relations one level up.

Goals

One reporter module renders quad rows; every verb report (status, get, post, patch) emits through it, and the old vocabularies retire everywhere at once.

  • status shows a quad for every non-.... path plus commit divergence in the same vocabulary.
  • get/post/patch reports are the transitions they produced — same table, same renderer.
  • Position is authoritative, color/style decorative: the | cat path stays fully readable uncolored.

Constraints

  • The spec is /wiki/Status; on any conflict the wiki wins.
  • This ticket is the REPORTING side only; the classifier input side is DIS-057 / /todo/STATUS/STATUS-013 ground.

WIP

Design decisions

  • Root = LCA(track, base); track/base/patch columns relate to ROOT.
  • RULED 2026-07-17: the wt column relates to BASE (the local-dirt axis) — a committed change is .v.., never .v.v; only uncommitted work lights the 4th char.
  • Chars . same, X removed, + created, ↑ advanced; columns blue/green/yellow/orange; bold staged, red conflicted.
  • Detached wt: track = the pinned hash, root = LCA as usual; no common ancestor = broken tree, refuse — never rendered.
  • Quad tok tags (2026-07-17, after the green-wt bug — I/J/O/K are diff-side BACKGROUNDS in the pager palette): the extension codes 26..31 ([ \ ] ^ _ <backtick>) = track/base/patch/wt glyph colors + staged-inverted + con-inverted.
  • Render (ruled through 4 iterations 2026-07-17): tty glyphs ● created / ∅ removed / ↑ advanced, and ✔ for a COMMIT row's o ("present in this line" — never the file ●); the GLYPH carries the column truecolor (blue/green/amber/orange RGB — 256-cube orange too muddy); staged wt INVERTS (color bg, RGB-white fg — basic 97 is theme-remappable), con inverts to red; plain stays the .xov canon; no bold, digit-counts idea DROPPED.
