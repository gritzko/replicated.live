Context

The code has NO be.todo_root (zero grep hits in be/); the landed URI-011 semantics resolve ANY dotless //name under SRC_ROOT via be.wtdir and decide local-vs-remote "by EXISTENCE, not shape" (core/loop.js:196-211, NAVNONE). The landed behavior looks intentional — the page likely predates URI-011's landing and should be rewritten to it.
  • Bro.mkd:44 documents the C bro keymap (h pops the view, d/u half-pages, ]/[ hunk motion, l opens, 32-deep stack); the JS pager binds h = HELP, back = -/BS, has no half-page or hunk-motion keys, and an unbounded stack (pager.js SHORTCUTS). One viewer, two keymaps — converge or split the page into C-bro vs jab-pager sections.
