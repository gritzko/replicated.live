Input

Context

  • Live evidence: curl localhost:8080/todo/STATUS/STATUS-018.html lines 19-23 — the whole indented meta block is one <p> inside the depth-1 <div> the 4-space indent opened.
  • Root cause: classify (render.js:413-453) tests fence, hrule, refdef, heading, todo, quote, ulist, olist — no meta pair — so the lines reach paraFlush as prose.
  • The grammar already exists ONCE: shared/ticketpage.js:105 META_PAIR /^(?: {4})?([A-Z][a-z][a-z0-9]): (.*)$/ and isMetaPair (:129).
  • render.js:370 already CONSUMES page.isMetaPair — but only to skip pairs when picking the OG description. The renderer knows the shape and renders it anyway.
  • Spec: /wiki/StrictMark "Renderers show a meta pair as a key–value row", "Key plus colon is exactly four chars, a native-width marker" — a block marker, not prose.
  • /meta/todo registers the ticket keys; the ticket-code ones are See: Sub: Dup: On1: On2:, and those values must click through.

Goals

The meta block renders as key–value rows and a ticket code in a value is a link to that ticket.

  • A Key: value line is settled by the BLOCK layer, never joined into a paragraph — at the head of a ticket and wherever else the shape matches (/wiki/StrictMark).
  • Each pair emits its own row with the key and the value separately addressable (e.g. <dl class="meta"> + <dt>/<dd>), so the HTML greps per pair.
  • See:/Sub:/Dup:/On1:/On2: values link to the ticket page, thin (todo/TOPIC/CODE.mkd) or fat (todo/TOPIC/CODE/README.mkd), per MARK-014's pageExists.
  • Verify through the render: STATUS-018.html shows six rows and a live link to STATUS-017.

Constraints

mark is JS ONLY — verbs/mark/mark.js + verbs/mark/render.js (MARK-013 ruling); beagle/mark is not the generator, do not read beagle/.

  • ONE grammar: consume shared/ticketpage.js META_PAIR/isMetaPair, never a second regex in the renderer — that is the drift STATUS-018 is about.
  • Non-ticket values stay VERBATIM (no inline layer inside a meta pair); only the ticket-code keys get linked. A URI value like Rev: ///be#4b64468c stays text.
  • Keep the Due\: escape working — an escaped key is prose, not a pair.
  • assets/css/style.css lives in the journal tree, NOT in ///be — do not chase it; report the class names you emit so the styling lands separately.
  • Clone ///be/ per /meta/work; on any clone failure stop and report.

WIP

Design decisions

  • The meta pair is a LEAF block like heading/refdef: enterLeaf(depth), flush the open paragraph, emit the row — it never opens or reuses a container.
