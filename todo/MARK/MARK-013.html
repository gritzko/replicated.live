Ruling (gritzko, 2026-07-29): mark is JS ONLY — the HTML generator is verbs/mark/mark.js + verbs/mark/render.js in the be tree; beagle/mark/MARK.c is NOT the site generator and is out of scope here. mark.js must support the new libdog StrictMark changes from BOTH DOG-024 (dog 737d196b: self-delimiting 4-char marker quads, blank-line-only paragraph breaks, one-tilde strike, literal escapes) and DOG-025 (code inners tokenized, formatting-blind).

Input

Context

  • Heading quads: a # run padded in ANY column ( ## , #, ####Smallest), level = COUNT of #; bare #### valid, a 3-char # prefix is a paragraph; the renderer trims the leading content space at depth*4+4.
  • Todo markers are exactly 4 chars (-[v]New gapless is a todo); one tab = one indent quad; --- short ruler; [x]: refdef quad.
  • A paragraph is broken by a blank line, not a line end — spans cross the wrap; paraFlush joins, but must agree with the lexer on continuation-prefix shedding (quote lines are MARK-005 ground).
  • Inline deltas: strike is ONE tilde ~x~ (~~ is an unmatched delimiter), \<char> escapes are literal-next-char (the swallow-to-the-closer form is retired).
  • DOG-025: code span/fence inners tokenize at word granularity, all tokens keep 'H', NO nested formatting inside — the renderer keeps emitting code bodies verbatim (no span/link/escape resolution inside <code>), span and fence paths both.
  • render.js classify (render.js:322) had drifted from the C grammar before DOG-024 already — the JS grammar must rejoin the lexer case-for-case; the dog reference case list is dog/test/TOK01.c MKDTBlockQuadTest + MKDTCodeInnerTest (in wt work/DOG-025).

Goals

  • mark.js/render.js accept exactly the DOG-024 marker shapes and trim the leading content space — rendered HTML for the existing corpus is byte-identical except where the old grammar was wrong.
  • Inline conformance: one-tilde strike, literal escapes, spans crossing wraps, verbatim code bodies (DOG-025).
  • make re-renders the site; the html/ diff is reviewed for stray changes and shows only intended fixes.

Constraints

  • Repro-first: JS test cases mirroring MKDTBlockQuadTest and the inline/code deltas, in the be tree's existing test arrangement, before the fix.
  • The quote/list continuation-join flush path stays MARK-005/MARK-001 ground — verify, don't rewrite.
  • Main-tree items (blog/follow-up.mkd:1 fourth prefix char, site re-render + html/ diff review) execute at land time, not in the worker wt.
