StrictMark was restructured 2026-08-12; after DOG-028 lands the lexer side, the JS HTML generator (be/verbs/mark) must render the new constructs: optional fence closers, captioned rulers, multiline leaf continuation.

Input

Context

be/verbs/mark/*.js is the generator (the C beagle/mark is dead, do not read beagle/). The site renders from wiki/, blog/, meta/ into html/ via make; html/ is generated output, writing there during verification is fine.

Goals

  • Optional fence closer: a dedent ends a code block; a bare closer is a no-op; a dedented opener chains snippets, none of them swallowing the rest of the page.
  • Captionless ruler renders <hr>; captioned renders a labeled divider — <div role="separator" class="hr">caption</div> with the rule line drawn both sides via CSS ::before/::after, caption centered.
  • Header text, ref def url/title, ruler captions and meta values join their one-quad-deeper continuation lines per the spec table.
  • Verify by rendering the live pages (StrictMark itself uses most constructs) and eyeballing the produced HTML.

Constraints

  • Work in a ///be/ worktree clone; no commit/post, put + report only.
  • Comments max 2 lines, start with MARK-016; keep the renderer's existing style.

Outcome

One file changed in the //MARK-016/ worktree (base ///be/#deb16de8): verbs/mark/render.js, staged, not committed. Suggested commit: MARK-016: optional closers, ruler captions, leaf runs.

  • classify() eats tabs as indent quads and records fence runs of any width (3/4 open, wider may close); ruler regex caps the dash run at four and captures the caption.
  • One contRun() implements the continuation law: markerless, non-blank, exactly one quad deeper; header/caption inline-join, meta verbatim-join, ref defs glue with "" so a wrapped URI reassembles.
  • Fence walk tracks the opener depth: deeper-or-blank is body, a bare opener-wide fence at opener depth is the consumed no-op closer, any other dedent re-classifies the line, so chained openers work and nothing swallows the page.
  • Corpus regression over 1012 pages: 7 improved (tab-indented lists un-glue), 14 todo/ pages degrade — their fence bodies are off-spec (not one quad deeper), the C lexer reads them the same; wiki/StrictMark.html byte-identical.
  • test/mark/meta + test/mark/og PASS; no tests edited.
