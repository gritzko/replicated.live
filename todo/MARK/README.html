MARK tickets: the StrictMark renderer (beagle/mark)

Tickets on the beagle/mark StrictMark→HTML renderer (C + ragel MARKE lexer): structure, nesting, budgets. Spec is StrictMark; wiki/blog rendering gaps that are page-content-side stay under WIKI. Each entry is one active ticket; it drops off once the ticket lands. The fix-and-land method is Issues.

Active tickets

  • MARK-001 MED — a list entry's SAME-DEPTH continuation line renders as a nested <p> inside the <li> instead of joining the entry's inline text (soft-wrap). FIXED in-tree 2026-07-07 (para_li flush mode, 7 new + 1 amended test case, orchestrator-verified; whole-wiki diff = POST.html + Submodules.html only) — UNCOMMITTED, pending land + site re-render + ~/bin/mark redeploy. Filed 2026-07-07.
  • MARK-002 HIGH — output cap len*8+16384 under-sizes dense-todo pages: a legit 9.6KB page → wholesale BNOROOM exit 22, one page fails a whole dir build; fuzz shares the 8× heuristic so it can't see it. Filed 2026-07-07.
  • MARK-003 HIGH — unknown CLI flags silently ignored: --strikt exits 0 where --strict exits 157 — one typo disarms the DIS-013 CI gate; needs a MARKARG refusal. Filed 2026-07-07.
  • MARK-004 MED — EOF inside an open fence unwinds containers BEFORE closing the fence: </li></ul> land inside <pre><code> (misnested tree). Filed 2026-07-07.
  • MARK-005 MED — quote-marker continuation lines render per-line (no soft-wrap join, no budget): a reflink wrapped across > lines emits raw [two\nwords] + a wrong anchor; route quotes through the para buffer (after MARK-001 lands). Filed 2026-07-07.
  • MARK-006 MED — .md second-class inconsistently (dir walk skips, dropext keeps .md.html, refdef href verbatim, implicit links DO rewrite) → dead links; needs a first-class-vs-refused ruling. Filed 2026-07-07.
  • MARK-007 MED — past MARK_MAX_REFS=512 the refdef collector silently stops: [R599] of 600 misresolves to the implicit ./R599.html — silent wrong link, no warning. Filed 2026-07-07.
  • MARK-008 LOW — CRLF input leaks \r into the HTML and budget counts; shed at line slicing. Filed 2026-07-07.
  • MARK-009 LOW — mark_refdef is a hand-rolled byte scanner (doctrine: ragel only), run twice per line; ragel-ize, byte-identical render. Filed 2026-07-07.
  • MARK-010 LOW — raw stack arrays (refs[512] 16KB, stk[64]) + raw linef[0][depth*4+2] indexing vs a_pad/carve/u8csAt idioms; pure refactor with MARK-007. Filed 2026-07-07.
