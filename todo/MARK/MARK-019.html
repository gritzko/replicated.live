A .mkd page's table (http://localhost:7777/impII/cat/ai/algo/Battle.mkd) renders as one run-on paragraph: mark/strict.js has no table case, though mark/html.js:317 already emits table/table_row/table_cell nodes for the GFM path (LITE-031, mark/gfm-table.js). DOG-053 makes a row a block leaf with its own marker quad (| , | , | , |; the delimiter row |--- / |:--) and cuts every cell | as a token. This ticket stacks those lines into the commonmark table nodes and makes them look right on bee http.

Input

Context

  • mark/strict.js::parse classifies a line's marker quad via quadKind/markList/markRule; a row quad would fall to "a marker off every known shape" and render as text.
  • mark/html.js:319 opens <tbody> only after a header row, so a headerless table (no delimiter row) emits no <tbody>; cells carry the obsolete align= attribute.
  • blob/style.css:24 has .mark table / th,td rules already.

Goals

  • Consecutive row lines at one depth make one table; rows above a delimiter row are header rows, the rest body; no delimiter → all body.
  • Cells split on the cell | tokens only (never a byte rescan, strict.js:1), each cell through inlineInto; the leading and trailing pipe make no empty cells.
  • Alignment off the delimiter cells (:-- left, --: right, :-: center), the first from the quad (|:--); reuse alignOf from mark/gfm-table.js.
  • A blank, another marker or a dedent ends the table; ragged rows padded to the widest.
  • mark/html.js: <tbody> for a headerless table, alignment as a class or style the stylesheet reads, a row's id="b<off>" like other blocks (BEE-052).
  • blob/style.css: header weight, alignment, a narrow viewport scrolls the table, not the page.

Constraints

  • Worktree ~/src/bee-MARK-019 (branch MARK-019); no main-tree edit, no commit (work).
  • Needs DOG-053's lexer: build quickjab against ~/src/dog-DOG-053 in a scratch build dir; do not touch ~/src/quickjab/build* in use.
  • RED first: a table fixture through bee mark (e.g. test/strict/), failing on the base tree; no existing test edited.

WIP

Design decisions

  • Rows are buffered per table and stacked at flush, since the head/body split and the padding need every row first.
  • The delimiter quad's tail (:--) is put back as its first cell's head, so all cells align through alignOf alike.
  • A markerless line one indent deeper appends to the last row with a break: | a | b + c | puts b c in one cell.
  • Only the first delimiter row delimits; a later one renders as a body row of dashes.
  • Alignment is class="al-left|right|center" only when the row carries boff (StrictMark); GFM keeps align= byte-identically.
  • <thead> spans all rows above the delimiter; a headerless table opens <tbody> at its first row.
