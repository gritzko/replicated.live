jab status takes 6.7s in a patched worktree and 0.13s in the same tree with no patch row in scope. The cost is the EXPECTED reading (/todo/STATUS/STATUS-017): per dirty patch-touched path, classify.js:expectedSha makes a PRIVATE weave.makeCtx(reader, path) and weave.build replays the FULL commit ancestry of the base tip and of every theirs tip, and weave.js:blobShaAt reads each commit's tree through treeMap — a readTreeRecursive FLATTEN of every leaf, per commit, per path. So the work is paths x commits x whole-tree, redone from scratch for each path, and each surviving fold burns a fresh 16 MiB abc.ram("WEAVE") through CFOLD. This is the JS twin of /todo/BLAME/BLAME-001, fixed on the C side by top-down OID descent (landed 1a5acce8); the cure is the same shape — walk down to the LCA only, and prune on an equal tree sha before any object is read.

Input

Context

Measured on //DIS-082-jab-3 (1583 files, root 28 patch rows, dog 14, ~300 commits of dog history).

  • work/DIS-082-jab (no patch row, same 1583 files) 0.13s vs work/DIS-082-jab-3 (patch row) 6.7s — 45x, entirely the EXPECTED axis.
  • Per-file: status dog/WEAVE.c (no EXPECTED) 0.07s, dog/CFOLD.h 0.52s, dog/INDEX.md 0.82s; status dog/ 6.4s ~= the sum of its ..vv/..oo rows — nothing is shared between paths.
  • Not I/O, not GC: strace -c gives 0.69s sys of 6.8s wall; JSC_logGC=1 gives 126 GCs / 199ms; 13.5k mmap/munmap pairs are the per-native-call 16 MiB BASS/WEAVE arenas.
  • JSC_useJIT=0 makes it 10.5s, so the 6s is JIT'd JS + native fold, not engine warmup.

Goals

Make the EXPECTED reading cost O(commits that touch the path, above the LCA), not O(paths x total history x tree size).

  • A new own module shared/pathdag.js: LCA floor, condensed per-path commit DAG, tree-sha prune — proposed API in "Design decisions".
  • weave.build folds only the retained commits, seeded at the floor; blobShaAt/treeMap leave the weave hot path.
  • One per-RUN cache threaded through every path from classify.js:classifyMerge (today each path gets a private treeCache).
  • A repro-first test asserting object reads/folds are O(changes), not O(ancestry) — the /todo/BLAME/BLAME-001 Step 0 shape.

Constraints

Reuse what exists; no parallel readers, no new descent code (/wiki/ABC reuse rule).

  • LCA is dag.mergeBase (GET-047), folded pairwise for N tips; walk cap stays dag.js WALK_CAP.
  • Path descent is store.js:descendPath (the KEEPTreeDescend twin) — do NOT hand-roll a tree walker.
  • weave.treeMap stays for classifyMerge's base/theirs tree ulogs, which genuinely want every leaf.
  • Status byte-parity: the emitted rows/buckets must not change on any tree, patched or not.

WIP

Design decisions

pathdag.of returns a CONDENSED DAG (only commits that change the path, edges collapsed through the pruned ones), which is exactly what foldCommit consumes.

  • pathdag.of(reader, path, tips[], cache, opts) -> { floor, seed:{blob,mode}|undefined, nodes:{sha->{blob,mode,parents:[sha]}}, order:[sha], truncated }, order topo oldest-first.
  • pathdag.at(reader, commitSha, path, cache) -> {sha,mode,kind}|undefined — descendPath by segment, memoised on (treeSha, seg): O(depth), replacing blobShaAt+treeMap.
  • pathdag.same(reader, path, treeA, treeB, cache) -> bool — lockstep descend, EQUAL subtree sha at any level returns true at once; this is the prune, and the reason at-per-commit alone is not enough.
  • pathdag.cache() -> per-RUN object keyed by TREE sha (not commit sha), so hits cross paths and cross tips; classifyMerge owns one and passes it down.
  • A retained merge survives only when its parents disagree on the path; an untouched merge collapses, so nodes[].parents are the retained parents.
  • opts.floor:"lca" seeds the weave from seed under the floor commit's weaveId — correct for EXPECTED/patch (only alive bytes are read), WRONG for why:/blame attribution, so blame passes floor:"" and gets the prune without the seed.
  • foldCommit then never calls blobShaAt: it takes node.blob straight to blobBytes, and the alive()+bytesEq adjacent-equal skip (weave.js:256, which today pays a full render per untouched commit) can go — by construction no retained node equals its parent.
