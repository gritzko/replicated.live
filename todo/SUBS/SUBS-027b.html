Input

Context

The landed slice classifies + flags be status, but three pieces are placeholders and the verb semantics are unenforced:

  • R1/R2 are not written by any code. SUBSDirty reads R1 as the live tree gitlink and probes R2 (usually ABSENT — your beagle case). The parent-pin reflog mirror and the ?.<parent> synth keep-alive must actually be emitted on post.
  • Edited (bit 0) is declared but a no-op — the recursive cross-store file-scan ≠ R4.base comparison is unwired, so today only Advanced drives status.
  • coord-mismatch unwired — the R2.<parent/branch> vs R3.branch check (record-health axis) is not computed.
  • Recursion semantics unenforced — the get reapply-onto-pin and the post OK/POSTNONE/error contract live only in the Submodules spec; sniff/POST.c + beagle/SUBS.c don't implement them. These files COLLIDE with in-flight SUBS-026 and PATCH-001.
  • be head can't see the pin axis — graf/LOG.c computes changed as committed-tree-vs-branch-tip; it structurally cannot see wt-vs-pin (the tree still pins the old sha). Needs a sniff→graf path.
  • Test gaps (audit of test/get,post,patch,status): Advanced/behind/diverged + all record-health are untested at GET/POST level (only patch/28,/35 cover advanced/behind); post/26+post/27 are WILL_FAIL stubs already encoding the post return-code contract, gated on "SUBS-001"; get/14 gates on an unimplemented be get --dry-run.

Goals

  • Write R1 (parent-pin reflog mirror) and R2 (synth dot-branch) on post; the classifier reads real records, the tree stays authoritative for R1.
  • Compute the Edited (recursive) and coord-mismatch axes so all three SUBSDirty axes are real.
  • Enforce the get (reapply onto pin) and post (OK→read tip + stage bump / POSTNONE→no bump / any sub error→HARD-ABORT the whole post; base≠pin-on-entry→error unless --force) recursion contract.
  • Surface Advanced/stale per sub in be head.

Constraints

  • SERIALIZE after SUBS-026 + PATCH-001 — they rewrite the same gitlink-bump path; concurrent land = non-FF race (work.mkd hazard).
  • Reuse the landed SUBSDirty (one classifier, every verb); ABC style; ragel for any parsing; no per-verb tree re-parse where R1 suffices.
