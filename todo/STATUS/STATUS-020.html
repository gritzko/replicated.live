be/shared/util/ignore.js (JS-031, the wt-scan .gitignore matcher) allocates 343 JS objects per match() call — measured 1,700 engine allocs per stat'd file on the pager crawl once the set chain, prefix + "/" + rel concat and isMeta's split("/") are added. One tty todo = 63M engine allocator ops, ~all in this matcher (alloc-weighted JS stack sampling, 9.4k samples: glob/tryMatch/setDecide/setDecideDeep ≈ 100% of traffic via wtScan→walk→match). This is the dominant term in the pager's first-frame lag on BOTH engines: be 2.8 s, quickjab 7.4 s (JAB-036 perf table).

Input

  • glob() recurses by pat.slice() + str.slice() — two fresh strings per level, and */** try EVERY suffix, each a new string. The C twin (dog/git IGNOGlob) walks indices, zero allocs; the port replaced pointer arithmetic with slices.
  • setDecideDeep() re-runs all patterns on every parent prefix (path.slice(0, i) per /) for every path — but the walk caller already decided every parent when it descended, else it would not be here.
  • match() per set per file: prefix concat; isMeta() splits the rel into a fresh array of segment strings.
  • journal's .gitignore = 19 live patterns, 8 of them unanchored basename globs (*.swp, *.log, build-*, ...) — each leads with *, so every check runs the suffix-try loop over the basename.

Measured (bench: real 19 patterns x 30k real journal paths, single set, quickjab+rpmalloc build, alloc counts via instrumented JSMallocFunctions):

variant allocs/path time (3x30k)
current setDecideDeep 343 2752 ms
index-based glob (charCodeAt, IGNOGlob) 6 2323 ms

Semantics: 0 decision mismatches across the 30k-path corpus. Residual 3-6 allocs/path = for-of iterator records; a plain indexed loop removes those too. Bench + sampler: ~/tmp/bench-ignore3.js, ~/tmp/qj-js-stacks.txt (2026-08-11).

The API

RULING (gritzko 2026-08-11): igno is THREE functions, per-FILE scope — open FILE / match / close file. There is NO walk, NO chain, NO anchor, NO prefix and NO repo-level dir hopping in C scope; repo borders are JS level. C's only fs touch is mmapping the one file it is named. JS holds one handle per .gitignore, walks its own chain (isRepo / declaredSubOf / $HOME stop — the hive rule, unchanged), folds precedence shallow→deep itself, and passes match() the already-prefixed path (today's tryMatch contract). Leaves land under dog.* (JAB-038 namespace; the mass move of the other libdog bindings is JAB-038's own work).

  • dog._igno_open(gitignorePath) → Number handle. Mmap + parse ONE .gitignore file. Absent/unreadable file → 0 (the common case — most dirs have no .gitignore; JS skips the level, no exception on the hot path). Throws in plain words on out-of-memory.
  • dog._igno_match(h, path, isDir) → TRISTATE Number: -1 no pattern matched / 0 negated (un-ignored) / 1 ignore. Includes the dir-prefix rule (a dir/ match on any parent prefix → 1, definitive). Tristate is forced: the JS fold needs a deeper set's negation to override a shallower ignore — a bool cannot carry it. Meta (.git/.be/..be.idx) is NOT here: per-file scope has no meta notion; the JS matcher keeps its isMeta.
  • dog._igno_close(h) → undefined, idempotent (0 / double-close safe, the _ulog_close precedent).

C surface behind the leaves, dog/git/IGNO.c: per-SET open/decide/close over one igno_set (igno_parse_set + igno_set_decide_deep already exist, today static). IGNOLoad/IGNOMatch/IGNOFree stay untouched (dog unit tests use them); nothing walks.

Allocation budget: per open — 1 mmap + 1 handle box; per match — zero in our code (stack pads + slices), 1 transient engine-internal cstring to read the JS string (JS_ToCStringLen / JSValueToStringCopy, freed same call, engine API tax); per scanned file ≈ 2 vs today's ~1,700.
