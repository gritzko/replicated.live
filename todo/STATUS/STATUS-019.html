STATUS-019: per-dir rev tree, the universal fs change witness

Now: OPEN Sev: MED Ask: gritzko Rep: ///be/ See: BRO-043 On1: JAB-032

Views recompute fs-derived state on every render; a todo re-render in the resident pager pays ~2.6 s of classifyMerge over 88 wts + 81 subs. Ruling gritzko 2026-08-04: replace BRO-043's per-repo value buckets with ONE cheap universal change witness — a rev tree like { "be": { rev: 3, sub: { "core": { rev: 2 } } } }: one shared counter, any fsw event increments it and stamps the event's dir AND every ancestor up the tree. shared/cache.js stores no view values anymore; each consumer keeps its own memo and compares the subtree rev it saw. Bigger views (todo, work) can then track many spots and skip recompute where the rev stands still.

Goals

The module shrinks to the rev tree; values move out to the consumers.

  • shared/cache.js API: start(root), poll(), rev(path) — arm lazily on the first query, answer the spot's rev (a live-watcher token when unarmed) — plus bumpRoot(), stop(), stats(); take/peek/drop/dropAll and the per-repo buckets GO AWAY.
  • On any event: bump the shared counter once, stamp the event dir's spot and every ancestor spot with it; siblings and descendants keep their revs.
  • OVERFLOW or a lost burst bumps the ROOT spot (every rev under it moves — all consumers miss); the pager's R/r maps to bumpRoot() (pager.js:568).
  • Ruling 4 verbatim: revs exist ONLY under a live watcher; failed start → rev() says so and every consumer recomputes; a missed event is never read as truth.
  • Port status.js: gatherRepo keeps its own {rows, state, rev} memo; the state fingerprint STAYS — shard refs move below .be/ (unwatched, object dirs churn), revs cannot witness them.
  • todo: memoize wtStat per wt keyed by rev(wtDir); gate foldSubs on the sub boundary's rev — the "cheap dirty probe" from the 2026-08-04 profile, item 2.

WIP

Design decisions

  • No watcher / unarmable dir → rev() hands out a FRESH never-repeating token, so a plain === compare always recomputes; a pre-JAB-032 jab (wd=0) yields tokens only, never an unwitnessed rev.
  • bumpRoot() stamps EVERY spot; the arming walk re-runs only when that spot's own rev moved.
  • stats() hits/misses tally at the rev level (same rev answered twice = hit), drops = bumps — keeps the pager's stats line and the untouched pty test meaningful.
