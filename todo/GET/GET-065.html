Port be's GET (GET) to bee over plain git: ONE repo→worktree verb that only fast-forwards and carries dirty edits along. Bare get is today's pull (sync.js:212); the new shapes are a branch, a path, a worktree and the forceful get!. Args are git-style refs and paths — RULING (gritzko 2026-09-19): RFC URI use is not necessary.

Input

Context

  • sync.js:187 integrate is the whole spine: fetch -q, merge -q --autostash --ff-only @{u}, the stash-tip tell, then follow.
  • sync.js:160 follow detaches every live sub to its recorded gitlink; GET-064 ruled a get that skips subs silently unacceptable.
  • be's "track" is git's @{u}, the branch's configured upstream; a fork's branch tracks the LOCAL branch it forked off (BEE-045).
  • Linked worktrees share one ODB (BEE-026), so a worktree source is a local ff, no fetch.
  • RULING (gritzko 2026-09-19): get/post REPLACE pull/push, reversing the BEE-037:8:KH and BEE-035:67:vi git-style naming.
  • act.js:35:1b one table row registers a writer, CLI and board button alike; a bang runner is the get! form (act.js:36:1b).

Goals

  • bare get: pull's exact behaviour and report line under the new word — ff to @{u}, autostash, subs follow.
  • get <branch>: switch the worktree to the branch, dirty edits carried; a branch checked out elsewhere is git's refusal, verbatim.
  • get <worktree> (a registry //name or a path): ff to the commit that tree is ON, merge --ff-only --autostash <sha>.
  • get <path>: recover a MISSING tracked file or dir from HEAD; a modified one is refused in words naming get!.
  • get! <path>: reset that path to HEAD (git restore), local edits discarded.
  • get! whole-tree: reset --hard to the target plus clean -fd, subs forced to their pins; the only destructive form.
  • RULING (gritzko 2026-09-19): every shape recurses into submodules by default — follow after each move, never silent.
  • A bareword is a path if it names a tracked file, else a ref (Verbs bareword defaults).
  • A diverged target refuses in one line naming the merge verb; nothing here ever makes a commit.
  • RULING (gritzko 2026-09-21): the report is the status QUAD summary (view/status.js:363:vX) of the rows this run moved.
  • The get <target> <sha> line plus the tally sub counts (sync.js:182) closes the summary; the exit status is honest.

Constraints

  • RULING (gritzko 2026-09-19): never write git's upstream or any other git setting, that is intrusive; @{u} is only READ.
  • git via argv spawn only (stage.js:31); no /bin/sh -c, no porcelain text parsing, NEVER a manual stash/pop (BEE-037:8:KH).
  • Out of scope: clone, the #~1 rewind (git has no ff-only backward), a file picked from another ref.
  • RED first over an origin+clones fixture (test/sync/run.sh precedent, a new test/get/run.sh); no existing case edited.
  • RULING (gritzko 2026-09-21): the verb lives in its OWN file verb/get.js; verb/ is the writers, view/ the read-only views.
  • Shared helpers (sync.js, stage.js, the shapeOf arg pick of verb/get.js) are required, never copied or forked.
  • RULING (gritzko 2026-09-21): worked in the MAIN tree, in sequence GET → POST → PATCH; no commit (work).
  • Comments per comment, GET-065 on the change.

  • Dirty carry on a switch: git switch -m iff it is shown to run the weave driver; else refuse on overlap. Verify before coding.
