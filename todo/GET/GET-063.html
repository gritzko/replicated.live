Context

Live hit 2026-08-13, main tree ~/src/journal/quickjab (disconnected from its parent repo since 2de1119b, so it has NO upstream source). Tip eebed237 pins sub dog#2375559d; that commit exists locally in the registered worktree //DOG-030-quickjab/dog (status lists 2 wt). Bare be get:

JS exception: be get: SUBFETCH cannot fetch sub dog (libdog) from (no same-source) or https://github.com/gritzko/libdog.git — child unreachable

  • SUBFETCH derives sub sources from exactly two places: same-source composition (EMPTY for a disconnected repo) and the .gitmodules official URL — which is stale identity here (quickjab carries its OWN dog since 2026-08-13; github libdog neither has the commit nor is the same repo).
  • It never consults: the sub's OWN tracked upstream (dog/.be get-rows, ///jab/dog — also without the commit here, but a legitimate source), nor the repo's registered worktrees, one of which HOLDS the pinned commit.
  • GET-037 is the adjacent-but-different SUBFETCH failure (self-gitlink, no .gitmodules entry); this one has a real declared sub and a locally present commit.
  • SECOND HIT same day: be post in worktree //DOG-031-quickjab (implicit pre-post get, parent advanced to eebed237, sub pin dog#2375559d) fails with the IDENTICAL message including "(no same-source)" — although a wt HAS a source (///quickjab), so same-source composition is broken even when the source exists, not merely absent.

Goals

be get in the parent brings the sub to the pinned commit whenever ANY locally known store holds it.

  • Source order for a sub pin: same-source (when it exists), the sub's own tracked upstream from its .be, the repo's registered worktrees composed BY PATH (//WT/ + dog -> //WT/dog/, the wt-URIs-compose-by-path ruling), official URI last.
  • Resolution of the pinned hash goes through be/core/resolve_hash.js (step 5.5 wt base) — no hand-derived fetch URLs or stores for worktree sources.
  • The error, when all sources genuinely lack the commit, lists every source TRIED in plain words.

Constraints

  • be/ JS only (verbs/get/get.js sub leg, shared/submount.js); repro first: a fixture parent+sub pair, parent disconnected, sub commit present only in a wt clone.
  • No behavior change for the reachable-upstream cases GET-047/GET-037 cover.
