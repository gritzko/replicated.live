WIP

Design decisions

  • THE TABLE (gritzko 2026-07-31), FF slice, rows = track vs root, cols = wt vs base:
    • n base: T. W. no-op / T. Wv OURS / T. Wx stays deleted
    • n base: Tv W. THEIRS / Tv Wv WEAVE3 / Tv Wx THEIRS
    • n base: Tx W. DELETE / Tx Wv OURS keep file / Tx Wx no-op
    • ot in base: To W- THEIRS / To Wo WEAVE3 (add/add) / T- Wo OURS untracked / T- W- no-op
  • BINARY is a modifier on the both-sides-edited cells ONLY (Tv Wv, To Wo) → OURS + conflict: binary is never woven, a dirty binary is never reset. The six clean cells are byte-agnostic.
  • Tv Wx is THEIRS regardless of bytes (gritzko 2026-07-31): a local delete carries no content, so nothing is destroyed, only an intent that costs one rm to reassert; a local EDIT carries content and wins.
  • Presence lives inside o/x, so the 12 illegal presence combinations of a bitmask cannot be written down, and edited-vs-locally-deleted stop sharing one "dirty" bit — the two defects of the current oldMap model.
  • DIVERGED = both track and base columns lit at once; that is the only shape needing a two-leg fold, and FF-only removes it from the non-force path. AHEAD lights the base column too but reads no-op via T., so it needs no special case.
  • get! bypasses the table entirely: unconditional THEIRS plus the untracked sweep — force stays the SOLE cleaning path (/todo/GET/GET-040's invariant).
