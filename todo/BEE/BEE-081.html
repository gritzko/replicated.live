An orchestrator dispatching workers needs the READY set every round: open tickets whose every On1: On2: … names a DONE ticket, in dependency order. Today that Gantt pass is done by hand off the ticket files. The On* and Now: fields are already in the kv index; the verb only has to join them across tickets.

Input

Context

impII work, 2026-09-28: every dispatch round the agent reads the tickets and orders them by hand.

Goals

  • bee todo --ready lists open tickets with all On* DONE (or no On*), dependency-ordered.
  • A dependency that is DONT or missing is shown, not silently counted as done.
  • A repro test over a small ticket set with a chain and a blocked ticket.

Constraints

Read On*/Now: off the kv index, no second parse of the ticket files; check be's todo for a port first.
