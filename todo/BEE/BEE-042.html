The row's COMMIT frame becomes be's history panel, 13 cols: [ ≡ +a -b ✓] — the ≡ log view button, the POSITIONAL ahbeh pair (POST slot first, GET slot second, a behind count never drifts into the push column — be views/todo/todo.js:855), a DIVERGED A⇄B as ONE button over both slots and their gap, and the commit ✓ as the frame's last slot. bee's commitFrame already computes a/b off model.commits (view/wtstat.js:74) but shows a tip hash and clicks nowhere; the tip cell retires in favour of be's geometry.

Input

Context

  • Buttons and their spells, git per BEE-037:
    1. ≡ -> log //<wt> — a VIEW push, empty context
    2. +a (ahead) -> push — git push
    3. -b (behind) -> pull — git fetch + git merge --ff-only --autostash @{u}
    4. A⇄B (diverged) -> merge — git fetch + git merge --autostash @{u}, weave driver, abort restores
    5. ✓ -> commit 'KEY: <bare title>' — lit iff staged > 0, blank otherwise (no grey ✓)
  • The diverged face is A⇄B right-aligned in 5 cells, each side clamped to 2 digits; a detached/upstream-less wt greys the pair dead (no spell names its tip — be todo.js:608).
  • The frame stays TOP-repo: ahbeh is the wt's own line (BEE-040).

Goals

  • Pager rows emit the panel off wtstat; push/pull/merge/commit clicks mutate + refresh in place (BEE-038), ≡ pushes the log view.
  • In-sync and wt-less rows: blank slots / ┄-fill, exactly the FILE panel's discipline.
  • Plain keeps ASCII frames; goldens change only per the BEE-039 layout ruling.

Constraints

  • Emission only; verbs, paint, dispatch are the deps'.
  • Worktree and build of the assignee's own; no main-tree edit, no commit (work).
  • RED first: TLV O-spell set per ahead/behind/diverged/staged fixture states; no existing test case edited. Comments per comment, BEE-042 on the change.
