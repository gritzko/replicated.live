///bee

"When did this pin value first appear" is answered with git log -S today. The index already maps a path to its revs, blobs, commits (REV-*) and commit dates (CTS), so the first rev whose blob carries the text, and its commit date, are one path scan plus blob reads.

Input

Context

impII work, 2026-09-28: checking when a pinned number (10016, 9075) entered web/data/cdpack.js.

Goals

  • bee log --born <path> 'text' prints the first commit (hashlet, date, subject) whose blob of the path carries the text.
  • A repro test with a value added in the second of three commits.

Constraints

Walk the path's REV chain off the index, no whole-history ODB walk; check be for an equivalent first.
