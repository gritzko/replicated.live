bee http paints a file as one <pre> of tok-X spans (render/html.js:343:bI) and never ships a script; DOG-048 now gives the same tok32 stream in the browser, dogtok.wasm, so a page can retokenize as it is typed. This ticket adds ONE endpoint, /<repo>/edit/<path>: GET serves the file painted by the same emitter, one div.ln per line and contenteditable, plus the one script; POST takes the new bytes back. The editor is basic on purpose: listen for input, remember the caret, relex a window around the change, reflush only the lines whose spans changed, restore the caret. Ruled 2026-09-07: one endpoint for both methods; regular pages include no editor script; the work lands in the main tree.

Input

Context

  • http.js:67:gw ROUTE names views; raw: (http.js:88:gw) is cat painted as source, the head picked at http.js:771:gw. edit follows that pattern, gated like a write: acts(st, mount) (http.js:466:gw) is "" under --ro.
  • http.js:609:gw actPost is the ONE write endpoint, its body a 4 KiB spell (MAXPOST); a file is not a spell, so the edit POST takes its own cap, MAXBYTES (4 MB), and the same sameOrigin gate (http.js:565:gw).
  • render/html.js:220:bI spansHtml clips a token to a byte window and render/wrap.js:301:aS indexRows cuts a hunk per logical line: the per-line paint is those two per row, a div instead of the \n.
  • render/html.js:410:bI page emits the sheet and the icon and nothing else; /style.css and /favicon.ico are read at startup off blob/ (http.js:675:gw).
  • quickjab/dog/tok/TOK.wasm.c:67 tok_parse(src, srcn, ext, extn, out, outcap) -> n (negative on refusal), tok_alloc/tok_free; the loader shape is quickjab/dog/test/wasm/run.js. Module: 6 wasi imports, 448181 bytes, built by quickjab/dog/test/wasm/run.sh (committed there as 346e603).
  • No lexer is line-local: block comments, fences and StrictMark spans cross newlines (quickjab/dog/tok/MKDT.c.rl:1, DOG-024) and the ragel state is private, so a restart point is proven by comparison, never read.
  • No node here; chromium is (quickjab/dog/test/wasm/chrome.py drives it headless with --dump-dom).

Goals

  • GET /<repo>/edit/<path>: the file painted by render/html.js's emitter as <pre class="body edit" contenteditable="plaintext-only" data-ext="<ext>" data-rev="<sha1hex>">, one <div class="ln"> per logical line holding its tok-X spans, no hrefs, no act forms, no byte-offset ids, no hidden U/O bytes; <script src="/edit.js"> on this page only. A dir, a blob, a non-UTF-8 or over-cap file, or a rev other than the tip refuses in words.
  • POST /<repo>/edit/<path>: the body is the whole file, Content-Type: application/octet-stream, capped at MAXBYTES; header X-Bee-Rev: <sha1hex> names the blob the page was served over. Same-origin and --ro gates as actPost; 409 with the current rev when the file changed underneath; 204 on a write, then cache.bumpRoot() (index/cache.js:86:_S).
  • /edit.js and /dogtok.wasm served as site files beside /style.css, read at startup off blob/, the module typed application/wasm. blob/dogtok.wasm is the DOG-048 build, copied in with its size and import list noted here.
  • blob/edit.js: the model is bytes + tok32 + a line table; the DOM contract is .ln per line, textContent of a .ln is exactly its line's text. Ctrl-S posts; the response line shows in the flash bubble (render/html.js:397:bI).
  • The raw and cat toggles gain an edit link when acts are on; the edit page's banner links back to raw.
  • Tests: test/edit/ — the window/resync algorithm as headless JS under quickjab over the native tok.parse (same tok32), the endpoint under test/http's harness (GET shape, POST write, 409, --ro 405, cross-origin 403), and one chromium --dump-dom smoke that types into the page and checks the reflushed spans.

Constraints

  • Regular pages (cat, raw, list, …) include NO script and paint byte-identical to today; ninja test green.
  • No manual URL or form parsing beyond what http.js already does; the ext reaches tok_parse whole, never split by hand.
  • Comment budgets per comment; blob/edit.js under ~400 lines, dependency-free, ES2020, no framework.
  • Main tree by gritzko's leave (2026-09-07); no commits, no push (work).

WIP

Design decisions

  • Windowed relex, proven by comparison (ruled 2026-09-07): take k lines above and below the changed lines, tok_parse the window, compare the FIRST line's spans with the old ones as they were and the LAST line's with the old ones shifted by the edit delta, tags and extents both; a mismatch doubles k on that side; byte 0 and EOF always match. Start k at half the value the previous keystroke ended on. Full relex when the window passes 256 KiB or the file is under 64 KiB.
  • Reflush by signature: after the splice, each line in the converged window recomputes its span list (tag + extent relative to the line start); only a line whose signature changed gets its .ln replaced, lines are inserted or removed where the line count changed, a \n inside one .ln's text splits it.
  • Caret as (line index, UTF-16 offset in the line's textContent), captured before the model edit and restored by walking the rebuilt div's text nodes; bytes in the model, UTF-16 in the DOM, converted per line.
  • The dirty range is the lines between the caret line before the input and after it, widened by the newline count change; IME input defers to compositionend. Undo is the browser's for now; an own stack is a later ticket.
  • One endpoint: the router maps edit like raw; handle dispatches on method before the view runs, so a POST never paints.

Blockers and bummers

  • A window cannot see an unterminated /*: dog's C lexer backtracks it to plain tokens, both edge comparisons pass, and the lines below stay stale. Healed by a deferred full relex (250 ms after the last keystroke) that reflushes only the lines whose signature differs; test/edit/model.js pins both the stale window and the heal on a >64 KiB fixture.
  • A trailing \n was lost on read-back with one .ln per line; ruled 2026-09-07 that .ln texts joined with \n ARE the file bytes, so a file ending in \n paints a trailing empty .ln (render/html.js:404:bI).
  • blob/edit.js is 529 lines against the ~400 asked; the comments were kept.
