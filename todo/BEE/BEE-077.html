A survey of bee/test/ against link (2026-09-22) found the anchor forms and scope queries pinned, but the target-vouching rules, the body limits and the scope negatives untested. This ticket adds a test per missing case; where a case fails, the bee code gets fixed too, and a grammar failure (tok/LINK.rl, a quickjab matter) is reported, not patched here.

Input

Context

  • Grammar of record: dog/tok/LINK.rl via tok.link (DOG-050, QJAB-015); bee consumes it in index/match.js, index/resolve.js, index/perma.js, index/hook.js, index/mint.js, view/cite.js.
  • Anchor forms are covered by test/anchor/anchor.js:24-58,85-192 and test/anchor/run.sh:94-157; permalinks by test/perma/pty.js:62-93; tickets by test/click/ticket.js:27-84; scopes by test/scope/scope.js:36-69 and test/scope/run.sh:93-133.
  • The only .xyz under test is the unslashed nosuch.xyz:9 in test/rst/run.sh:331, asserted plain because it resolves to nothing, not for a grammar reason.
  • test/scope/run.sh:4 names the .c:/re/ scope in its header, but no leg runs one.

Goals

Uncovered, one test per line; each pins the ruling in link and BEE-073:

  • abc/Makefile:20 and abc/Makefile:'ragel': an ext-less name vouched by a line or a delimited anchor past a slash.
  • src/weird.xyz:12: an unknown extension vouched past a slash, the positive form.
  • ./view/pager.js:452 the ./ head; /README:10 a rooted ext-less target; rooted /README with no anchor stays prose.
  • DOG-034:name: a ticket with a symbol anchor.
  • A symbol vouches for nothing: either/or:pick and abc/Makefile:sym stay prose.
  • One-line bodies: a newline in a body, a range (12,20) and a compound (1599/re/) are not anchors.
  • The caps of DOG-050: a 64-byte body, a 32-char symbol, an unclosed delimiter (main.c:'open is main.c plus prose).
  • A regex ending in * inside a C block comment, and its {0,} spelling, resolve alike.
  • A scope with a regex anchor end-to-end: .c:/u8\w+Feed/.
  • A scope with a line anchor is nothing: .c:30; a scope never mints, through bee mint and the commit hook.
  • A scope takes no stars: **/*.c:'x' stays prose.

Partially covered, to complete:

  • abc/.c:"malloc($1*$A);" queried end-to-end, $-variables inside a scope (now split only, test/anchor/anchor.js:64-67).
  • //libdog/.h:'ok64' as a real cross-repo scope run (now urlOf only, test/anchor/anchor.js:232-239).
  • A double-space gap read from the source when the rendered page collapses it.

Constraints

  • Tests go into the existing dirs (test/anchor, test/scope, test/perma, test/mint, test/hook, test/click), one leg per case, in the style of their neighbours.
  • No other tests are edited; a case that contradicts a live test is reported with both lines cited.
  • Fix bee code where a test fails; if the failure sits in tok/LINK.rl, report the case and leave it red-marked, not patched.
  • Work in the main tree (ruled 2026-09-22); no commits.
