be's token diff (~/src/journal/be/view/bro.js:393-491, C twin dog/HUNK.c) decides per line whether a change paints INLINE (one row, both sides in place, pale wash) or SPLITS into an rm row and an in row (each hiding the other side, strong wash). bee's render/wrap.js had PASS_NORMAL only — every diff line rendered inline with the strong 157/217 wash, a whole-line replacement smeared as two2. This ticket ports the classifier, the two-pass walk, the pass-aware row end and the four wash slots; the consumers (pager.js emitBody, view/diff.js sides) were pre-wired for r.pass.

Input

Context

Recovered 2026-08-17 from bro.js; landed in the ~/src/bee3 worktree.

  • classifyLines (bro.js:393): per 'n'-delimited segment tally visible bytes by side (inB/rmB/eqB, U/O bytes excluded) plus bnd, the side of the 'n' itself.
  • lineKind (bro.js:419): changed = max(inB, rmB) (BRO-041, gritzko 2026-07-29 — in+rm charged a symmetric swap twice); changed == 0 EQ; eqB == 0 pure in / pure rm / split when both; else INLINE iff changed*4 < changed+eqB, SPLIT otherwise.
  • lineContinues/passSeesNL (bro.js:434-443): a one-sided 'n' with the other side present bleeds the segment into the next; the rm pass ignores IN newlines and vice versa.
  • walkHunk (bro.js:448): an EQ/INLINE segment with an EQ boundary is one NORMAL row; anything else opens a block to the next such segment whose predecessor does not continue, emitted twice — RM rows then IN rows, grouped across the 'n's the pass cannot see, empty rows dropped.
  • rowEndPass/paintDiffRow (bro.js:364, 499): a split pass hides the other side's bytes; NORMAL hides nothing.
  • cellAnsi + WASH (bro.js:184, 347; theme.js:126): I/O = pale 194/224 (inline, or the other side seen from a split pass), J/K = strong 157/217 (own side on its own pass).
  • Not ported: the DIFF-016 patched-in family (bee stamps no tok32 bit 26); DIFF-017's glue/whitespace-only refinement (never landed in be either).

Goals

  • wrap.indexRows routes a hunk with diff sides through the two-pass index; rows carry pass in {NORMAL, RM, IN}.
  • ansi.cellAnsi(tag, pass, side) paints the four slots; emitBody, rowEnd, pager._rowToks, pager._screenToByte skip what the row's pass hides through ONE predicate wrap.passHides.
  • Repro test over hand-built weaves: BRO-041's -[ ]→-[x] line stays ONE row; a full-line swap splits; a one-sided 'n' groups the rm row.

Constraints

  • Parity with bro.js, not improvement — the be classifier is the spec, including its known rough edge (an inline row shows both sides adjacently: -[ ]-[x] uniform headers).
  • render/html.js paints the same rows: hunkHtml walks wrap.indexRows for a diff hunk, side-in/side-rm strong on the own pass, .pale inline or from the other pass; the row's 'n' is a terminator, not a span (test/http/url.js amended accordingly, 2026-08-17).

WIP

Design decisions

  • passHides(tag, pass, side) lives in wrap.js and is the one hidden-byte rule; every walker (index, paint, click map, followable toks) reads it, so a hidden byte takes no column anywhere.
