The trail ticket → commits → files is asked for every landed ticket; now it is git log --grep. Commit subjects start with the ticket code (comment), so a bee log TKT-123 (or --ticket) lists the commits whose subject starts with TKT-123: plus the paths each touched.

Input

Context

impII work, 2026-09-28. Subjects are not indexed; the CPAR walk reaches every commit and a hashlet reads its subject off the ODB (INDEXES.mkd, "What the records buy").

Goals

  • bee log TKT-123 lists those commits newest-first, each with its touched files.
  • A repro test on a tiny repo with two tickets' commits interleaved.

Constraints

No new index kind unless the walk is measured too slow; check be's log for a port first.
