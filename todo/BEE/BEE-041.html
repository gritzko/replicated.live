The board row's FILE frame becomes be's staging panel: [ i ~n -n +n ] — the i view button, three three-state class buttons, the last slot blank until CI gets its ticket. Today bee hangs ONE U:"list <root>/" on the whole frames region (view/todo.js:556:i4) and the frames are inert text; this ticket retires that U and emits per-button 2-cell click zones over the BEE-039 model, each minting its verb.

Input

Context

  • Buttons and their spells, git per BEE-036:
    1. i -> status //<wt> — a VIEW push, empty context, the wt is the arg (be todo.js:806:i4)
    2. ~n -> add — stage the modified class
    3. -n -> rm — record the gone class
    4. +n -> add + — stage the untracked class
  • Three-state per slot: unstaged lights (wash + O), wholly staged is info (colour, no wash, empty spell), empty blanks; nothing inside the brackets is ┄-filled.
  • Counts are the whole tree's once BEE-040 lands; until then the frame shows the top repo and must not pretend otherwise.

Goals

  • Pager rows emit the panel; every cell of a face paints and clicks; a wt-less row ┄-fills the region as today.
  • A class click stages, the row re-buckets in place (BEE-038); the i click pushes status.
  • Plain/--plain/pipes: the frames keep their ASCII text, zero O bytes, zero SGR — test/elastic/board parity per the BEE-039 layout ruling only.

Constraints

  • Emission only — no verb, paint or dispatch logic here; those tickets are the deps.
  • Worktree and build of the assignee's own; no main-tree edit, no commit (work).
  • RED first: TLV asserts the face+O pairs and their ABSENCE in plain; no existing test case edited. Comments per comment, BEE-041 on the change.
