The board's trailing ticket-state panel, be's donePanel (views/todo/todo.js:885): ONE frame, TWO live buttons — ✓ mints done <KEY>, ✗ mints dont <KEY>, context-less, the KEY is the argument. The verb flips the page's Now: meta pair (DONE / DONT) and retires the ticket's worktree. RULING (gritzko 2026-08-20): the wt MOVES to a done root — $SRC_ROOT/done/<name> — with git worktree repair making git's back-pointers follow; nothing is ever deleted. The meta-tree law is be's (BE-040): the verb EDITS files, it never commits them — review and commit stay with the user.

Input

Context

  • bee tickets carry state in Now: meta pairs, not header [MARK]s (todo); index/kv.js reads them but nothing in bee writes a page yet — this is bee's first meta-tree write path.
  • The page resolves by KEY through the board's own ladder (view/todo.js pageFile kin); the wt by the ticket-key match on the scanned names (view/todo.js:445 wtsOf).
  • The panel: dim brackets, a dim gap, each 2-cell face its own click zone; [ ✓ ✗], 7 cols (be PANELW).
  • Git for the retirement: git -C <main> worktree move <wt> $SRC_ROOT/done/<name> where git allows, else rename + git worktree repair; a sub's linked worktrees (fork.js:94 layout) move WITH the dir and repair per-repo.

Goals

  • done KEY... / dont KEY...: set Now: DONE / Now: DONT in the page head (add the pair when absent), one confirmation row per key (key + title).
  • Idempotent: an already-closed page answers "(already closed)", zero edits; a KEY with no page is one line done: KEY: TODONONE; an odd head reports VISIBLY and skips (be BE-040 r2 lesson — never a silent io.log).
  • The wt retirement: clean or dirty, the move preserves everything; no wt is fine; a move refusal reports and leaves the page flip done.
  • The board drops the row (the open filter reads Now:), and $SRC_ROOT/done/ never lists as a ticket wt (wts.scan excludes it).
  • The panel emits on every OPEN pager row; plain stays chrome-free.

Constraints

  • File edits only in the meta tree — no commit, no push, ever; mutations confined to resolved page paths, no concat escapes (be BE-011 class).
  • git via argv spawn; worktree and build of the assignee's own; no main-tree edit, no commit (work).
  • RED first over a fixture board + fixture wt; no existing test case edited. Comments per comment, BEE-043 on the change.

WIP

Design decisions

  • The Now: flip is a head-scoped line edit (the pair sits in the meta block under the header, each key at most once) — never a body-wide replace.
  • Delisting is NOT needed: bee's open filter is the Now: pair (BEE-025), topic READMEs are landing pages, never an index.
