BEE-028: http URLs always spell the verb — /repo/verb/arg, no verb-less path form

bee http serves two URL shapes under one prefix: /<repo>/<verb>/<arg> and the verb-less /<repo>/<path> (BEE-003 ruling 2, the form references resolve to). They share a namespace, so a path whose first segment spells a verb name is shadowed by the verb — todo/ since BEE-025, log/, tree/, list/, blob/ in principle. Seen 2026-08-19: a ticket page linking todo/BE/BE-038.mkd got the href /bee-journal/todo/BE/BE-038.mkd, which ran as todo BE/BE-038.mkd and refused. Ruling (gritzko 2026-08-19): remove the ambiguity by grammar — every emitted URL spells its verb, verb names always win on the way in.

Input

Context

  • Have: http.js routeOf — the first segment after the repo is a verb when ROUTE knows it, else the rest is a path (verb: "path", then cat for a file, list for a dir); refResolve emits the verb-less form for references; argUrl emits /<repo>/<verb>/… for nav spells.
  • Have: the stopgap in the main tree (uncommitted, same day): refResolve writes the verb out when the path's first segment is a ROUTE key, and /todo/<file> is served as the file by a fs stat — a heuristic (/todo/done, a fat ticket's dir still run as the verb).
  • Pinned hrefs: test/http/run.sh ("a reference resolves to the verb-less /repo/<path>"), test/todo/run.sh leg 1h, test/click, test/refline, test/land, test/perma.

Goals

  • Every href bee http emits is /<repo>/<verb>/<arg>: a file reference → /cat/<rel>#b…, a dir reference → /list/<rel>/, images keep /bytes/, nav spells keep argUrl.
  • routeOf: after the repo, a segment that names a verb IS that verb, always; /bee-journal/todo/BE/BE-038.mkd is todo BE/BE-038.mkd and refuses with a hint naming the path form (try /bee-journal/cat/todo/BE/BE-038.mkd).
  • A verb-less URL whose first segment is NOT a verb (/bee-journal/README.mkd, bookmarks, typed URLs) stays a convenience: a 301 to its cat/list form, so the address bar shows the canonical spelling.
  • The stat heuristic of the stopgap goes away; the todo verb never reads the fs to decide what it is.
  • Tests: the pinned hrefs move to the verb form; a check that /todo/<file> under a repo with a todo/ dir refuses with the hint; a check that the verb-less form redirects.

Constraints

  • BEE-003 ruling 2 is amended, not the rest of it: the repo stays the first segment, submodules stay addressed through the parent (ruling 5), choose and bytes are untouched.
  • No new verb, no sigil (/:todo, /~/) — the fix is "spell the verb", nothing else; ROUTE remains the one table.
  • The pager is not affected: nav spells already carry the verb; only http.js and the suites move.

WIP

Design decisions

  • RULED (gritzko 2026-08-19, this ticket): /repo/verb/arg in all cases; verb names win; verb-less non-verb first segment = redirect, not a 404.
  • The hint on a verb miss is the verb's own error plus one line, so todo's "not a ticket code…" message stays as is and the router appends the path form.
