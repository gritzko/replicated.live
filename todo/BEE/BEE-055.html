Context

BEE-047 paints the act's one report line as a viewBar pseudo hunk header on top of the page the 303 lands on (http.js:770). It reads as content, shifts the layout down, and a browser's back/forward cache re-serves it (no Cache-Control), so a spent flash reappears — reported by gritzko 2026-08-21.

Goals

The flash is a NOTIFICATION BUBBLE: a fixed overlay that does not disturb the document flow, somewhat transparent, with an [x] close button. Act errors ride the same bubble (they already flow through st.flash via why(e)). Pages send Cache-Control: no-store, so a spent flash never replays from cache.

Constraints

Colours stay with the theme half (render/html.js stylesheet); blob/style.css carries geometry only. No script block — at most one inline handler for [x].

WIP

Design decisions

  • html.flash(line) emits <div class="flash"><pre>…</pre><button>×</button></div>; http.js:770 spends st.flash into it instead of viewBar.
  • .flash is position:fixed top-right, opacity:.93, banner tone from the theme.
  • no-store rides sendPage's HTML responses only; /style.css stays cacheable.
