JS-068: predictable /tmp post-barrier scratch path (symlink/TOCTOU + collision)

Now:
STALE

verbs/post/post.js's barrierPath() builds the commit-JOIN scratch ULOG. For a secondary .be-FILE repo (no .be/ dir) it falls back to a PREDICTABLE /tmp/.bepost.barrier.<USER>.<bePath-with-_>, later opened O_CREAT|O_RDWR|O_TRUNC with NO O_NOFOLLOW/O_EXCL — another user can pre-plant a symlink there and the open follows+truncates the target (CWE-59). The name is not PID-keyed, so same-user concurrent posts collide on it too. Method: Issues.

Input

Context

  • verbs/post/post.js:267 barrierPath(info) — the JOIN scratch path.
  • :269 primary .be/: <dir>/post.barrier (fine, in-repo).
  • :271 secondary .be-FILE fallback: "/tmp/.bepost.barrier." + (io.getenv("USER")||"x") + "." + key where :270 key = bePath.split("/").join("_") — fully attacker-predictable.
  • Predictability: any user knowing the victim's bePath (and $USER) knows the exact /tmp name; world-writable /tmp lets them pre-create it.
  • No PID/nonce in the name → two concurrent be post runs on the same repo share one barrier file and corrupt each other's fold (cited POST).
  • The open is O_CREAT|O_RDWR|O_TRUNC (no O_NOFOLLOW/O_EXCL), so a planted symlink is followed and its target truncated.

Goals

  • The secondary-repo barrier is created in a path an attacker cannot pre-plant, and never follows a symlink / truncates a pre-existing file.
  • Same-user concurrent posts on one repo no longer collide on the scratch name.
  • A repro test: a pre-existing symlink at the computed path must NOT be followed (open fails / picks a fresh name), not silently truncate its target.

Constraints

  • Mirror the native barrier semantics (the JOIN fold + cleanupBarrier :281 unlink-after-fold); keep the primary .be/ :269 path untouched.
  • Pure JS over io.*; reuse ulog.*. Scope: barrierPath() + the open site.

WIP

Design decisions

  • Create the scratch under a per-user 0700 dir (e.g. $TMPDIR/$XDG_RUNTIME_DIR fallback /tmp/.be-<uid> made 0700) with O_EXCL|O_NOFOLLOW, or via an mkstemp-style random suffix; refuse a pre-existing path.
  • Add a random nonce (and/or PID) to the name so concurrent same-user posts get distinct barriers.

TODOs

Blockers and bummers

  • O_NOFOLLOW/O_EXCL primitive: no longer needed (no scratch file).

Outcome

  • MOOT via JSQUE-020 928aaad5 (be/): the durable post-barrier scratch ULOG was removed — the commit JOIN now folds the in-memory decision set (verbs/post/post.js:650-652 comment "the former durable back-scan barrier only re-derived a leaf count, so assert it in-memory").
  • 2026-07-07 audit: zero bepost/barrierPath hits across be/; the predictable-/tmp-path, TOCTOU and same-user-collision surfaces are all gone with the file.
