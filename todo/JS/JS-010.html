JS-010: boundary cleanup — JSStringRef leaks + callback re-entrancy / exception safety

Now: DONE

JSValueToStringCopy refs are never released, and the poll callbacks re-enter JS that can mutate JS_FILES/JABC_TIMER mid-loop while a C++ throw unwinding through a C-ABI callback is UB. Method: Issues.

Input

Context

  • (a) JSValueToStringCopy returns a +1 ref never released — utf8.cpp:18 (JABCutf8Encode), convert.cpp:77.
  • (b) Poll callbacks (timeout_cb io.cpp:176-189, JABCioNetOnEvent io.cpp:281-336) re-enter JS that can mutate JS_FILES / JABC_TIMER mid-loop with no guard; a C++ throw unwinding through these C-ABI callbacks is UB.
  • WITH_JS-gated WIP; convert.cpp is the dead rdx path, utf8.cpp is live.

Goals

  • Every JSStringRef released; callbacks survive re-entrant JS_FILES/JABC_TIMER mutation; no C++ exception escapes a C-ABI callback.

Constraints

  • Pair every JSValueToStringCopy with JSStringRelease; wrap callback bodies in try{}catch(...){} (effectively noexcept); document the single-thread contract and add a re-entrancy assert.

WIP

Design decisions

  • (open) Add the release at each site; make the callbacks exception-safe and re-entrancy-aware.

TODOs

  • Repro-first: a callback that schedules/cancels a timer or closes a file mid-loop does not corrupt the table; a throwing callback does not escape.
  • Add JSStringRelease + the catch(...) guards + the contract note/assert.

Blockers

  • None.

Outcome

  • LANDED f20e2ec7 (2026-06-16): audited io/utf8/main.cpp — no remaining live JSStringRef leaks (all paired w/ release; the cited utf8:18 was JS-003, convert.cpp is dead); wrapped both poll callbacks (timeout_cb, JABCioNetOnEvent) in try{}catch(...){} + a single-thread re-entrancy guard (JABCioReentry). C++-throw containment verified RED (abort) → GREEN via a new jabc_test row.
