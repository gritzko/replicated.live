JS-079 MED: verbs/get/get.js fan-out reads ctx._get with no guard

The get fan-out smuggles whole-run state through ctx._get (the pinned reader + wt + kinds map), but ONLY handleSeed sets it; reconcileDir/leaf/delSweep all assume it is present. Fine on a fresh run where the seed row dispatches first, but if the queue ever resumes PAST the consumed seed (a survivor resume, JSQUE-003), these children dispatch with ctx._get===undefined and throw a bare TypeError instead of a clean refusal. It also violates the loop per-row contract (state on ctx, not the row). Method: Issues.

Input

Context

  • verbs/get/get.js:187 — `ctx._get = { k, wt, tip, oldTip, fresh, branch,

    ts, kinds, dels } is set ONLY in handleSeed`.

  • :268 reconcileDir: const g = ctx._get; then treeMap(g.k, …) — a

    null g throws TypeError: Cannot read properties of undefined at g.k.

  • :318 leaf: const g = ctx._get, out = ctx.out; then g.wt/g.k — same

    bare TypeError on a seed-less dispatch.

  • :365 delSweep: ctx._get.delSwept = res.acc; — null-deref on assign.
  • Dispatch (:165-170) routes a non-seed, non-delsweep row straight to

    handleReconcileOrLeaf; no row carries the pinned reader (the queue round-trip keeps only the URI, comment :264-266).

Goals

  • A reconcile/leaf/delsweep row arriving before its seed REFUSES cleanly

    (a named throw), never a bare TypeError.

  • A repro that dispatches a get ?<tree>#<old> row on a ctx with no _get

    and asserts the clean refusal.

  • Keep the fresh-run fan-out byte-identical (the guard is a no-op there).

Constraints

  • verbs/get/get.js only; no change to the seed-pin shape (JSQUE-004).
  • Either guard the children or re-derive coordinates from ctx.resolved;

    do NOT widen the per-row contract. A few LoC.

WIP

Design decisions

  • Cheapest: a guard at the head of each child — `if (!ctx._get) throw "be

    get: reconcile row before seed";` — turns the latent TypeError into a named refusal and documents the seed-first invariant.

  • Alternative: re-derive { k, wt } from ctx.resolved/io.cwd() so a

    resumed fan-out self-heals; heavier, only if resume must survive.
