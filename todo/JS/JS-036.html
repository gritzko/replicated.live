JS-036: git.delta.encode — git delta producer over dog/git/DELT

Now: DONE

Expose DELTEncode as git.delta.encode(base, target, out), the twin of the existing git.delta.apply. The missing primitive for delta-compressing objects in a pure-JS git-wire client (thin packs, push deltas). Method: Issues.

Input

Context

  • git.delta.apply (JS-024) reconstructs a target from base+delta, but JS cannot PRODUCE a delta — dog/git/DELT.h::DELTEncode (libdog, already included by js/pack.hpp) does, and is unbound.
  • Prereq for JS-037 (REF_DELTA bodies) and the future wire push/thin builder.

Goals

  • git.delta.encode(base, target, out) -> n — append the delta instruction stream to out (Buf IDLE), advance fed, return n.
  • DELTFAIL (delta not smaller than target) → return -1 so JS falls back to raw, never throws on the expected "store raw instead" path.

Constraints

  • Pure marshalling over DELTEncode (libdog). No new abc, NO dog. Caller owns out; the leaf sizes nothing (rule #4).

WIP

Design decisions

  • Native leaf _delt_encode(base,target,out,outOff) -> n | -1 in js/pack.hpp (beside _delt_apply); installed via JABCPackInstall.
  • JS surface git.delta.encode in cont.cpp beside git.delta.apply; -1 surfaces verbatim (caller's raw fallback), DELT I/O errors throw.
