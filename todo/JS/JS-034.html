Context

  • JS-027 does be status in pure JS over existing bindings; some paths may be too slow/awkward. Concrete gaps surfaced during JS-030..033 (all worked around in JS, parity still byte-identical — these are convenience/perf leaves, libdog/abc):
    1. io.stat returns {size,mode,kind} only — NO mtime; classify spawned stat -c '%Y %n' (chunked ≤200 paths — a 2955-path argv overflowed spawnFds scratch). A thin mtime field on the stat leaf removes the spawn.
    2. io.stat follows symlinks (FILEStat not FILELStat) + no io.readlink — a dangling symlink throws; symlink content unconfirmable. Want lstat + readlink leaves.
    3. pack.scan/pack.resolve (PIDXScan/PACKResolveOfs) fail on REF_DELTA — fine for keeper (OFS-only per PackLog invariant), but foreign imports need a sha-base resolver.
    4. io.readdir hidden:false drops dotfiles — needed hidden:true to scan a tracked .gitignore (only .git/.be should be meta-filtered).
    5. classify quirk: a stamped wt-only file reads unk where native shows new (SNIFFAtKnown new branch) — orthogonal; only bites be-redirect files inside a recursed sub.
    6. Optional: ULOG has(ts)/row(i) index, git/IGNO matcher, HUNKu8sFeedRow (ULOG→HUNK serialize) — currently done in pure JS, would be tidier as libdog leaves.
