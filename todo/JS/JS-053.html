JS-053: bin/bro.js — the syntax-highlighting pager as JS (+ a tty leaf)

Now
DONE

Mirror bro (the dog toolchain's TUI pager/renderer) as bin/bro.js on jabc, the JS-027/JS-038 way. A SELF-CONTAINED viewer: URI args → io.mmap+tok.parse in JS → hunks → paint. NO stdin TLV pipe and NO forking C producers — bro.js RUNS JS commands for its content (view / search / open) in-process; that is the point. The native gap is tiny — a terminal-control leaf (raw-mode + winsize); the bulk is a pure-JS port of bro/BRO.c (renderer + colour-diff + TUI). Method: Issues.

Input

Context

  • bro (bro/INDEX.md, README.md): indexes hunk TLV records into rows, paints cells from tok32 tags + a THEME, and classifies diff lines (bro_classify: EQ/PURE_IN/PURE_RM/MOD_INLINE/MOD_SPLIT, the 25% inline-vs-split rule). TUI in BRO.c: raw-mode loop, 32-deep view stack, search, :/# GURI prompt, status bar.
  • bro reaches libc ONLY for terminal control: tcgetattr/tcsetattr raw mode (BRO.c:320/341), ioctl(TIOCGWINSZ) size (:353), sigaction(SIGWINCH) (:3050), open(/dev/tty). abc/TTY.h is escape-FORMATTING only, not control.
  • Already bound: tok32 highlight (JS-023), the HUNK TLV cursor, uri, io.mmap/readdir/spawn/read/write, the pol loop, ansi. THEME (tag→SGR) and the SGR-1006 mouse decode become pure-JS tables/decoders.

Goals

  • Native: an abc/TTY (or abc/FILE) raw-mode + winsize wrapper (libabc, the JS-047 leaf pattern) → bind tty.raw/tty.cook/tty.size (+ /dev/tty open). Optional: bind abc/ANSI ANSIu8sDrainCSI for key/mouse-escape decode.
  • bin/bro.js + bin/lib/*: the pager — event loop + keymap, row index + cell painter, the colour-diff classifier, codepoint soft-wrap, the 32-deep view stack (scroll preserved), the live status bar, the :/# prompt, in-view search.
  • Content built in JS: a URI arg → io.mmap+tok.parse → one HUNK; a dir → io.readdir → one 'F' hunk per entry. Hunks live in JS; no external feed.

Constraints

  • libabc+libdog ONLY. NO stdin TLV ingestion and NO forking C producers (spot/graf): bro.js obtains content by running JS commands in-process — the whole point. Cross-file : spot search needs a JS spot (absent) → deferred.
  • Terminal restore is a HARD safety: cook-on-exit on EVERY path — a try/finally around the loop AND an uncaught-throw hook in main.cpp (JABCRun routes the throw) — or a crash wedges the user's shell in raw mode.

WIP

Design decisions

  • Skip SIGWINCH: re-query tty.size on each ~100ms input tick (VTIME-style) and re-render on change — no signal binding needed (the lone optional native bit).
  • Painter stays viewport-only + incremental (bro paints only visible rows) so a per-keystroke re-render is cheap over big hunk sets.
  • THEME is a pure-JS tag→SGR table (the README set D/G/L/H/R/P/S/N/C/F/U); the SGR is emitted via ansi.cpp or a bound abc/ANSI delta.
