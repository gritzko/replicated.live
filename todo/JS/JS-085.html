JS-085: views/log/log.js::resolveHashlet re-impls store.resolveHexAny via test-only k._packs()

Now
OPEN
Sev
HIGH

be log:#<hashlet> resolves a short hex to a full COMMIT sha. The log view's resolveHashlet (log.js:104) bypasses the public reader API: it reaches into the test-only k._packs(), re-mmaps every pack (already cached by the store), and re-runs a full O(all-objects) decompress-and- prefix-match scan that near-verbatim duplicates store.resolveHexAny + indexPackByWalk. commit.js already does the same job in ~6 lines. Method: Issues.

Input

Context

  • log.js:109 packs = k._packs() — _packs is store.js:551 marked "expose for tests / verification", NOT a reader verb.
  • log.js:111-130 re-mmaps each pack (git.pack.mmap), walks every offset, inflates each object (pk.resolve), reframes the sha, prefix-matches, and re-detects ambiguity.
  • This is the exact work store.js::resolveHexAny (:302) + indexPackByWalk (:95) already do over the cached wh128 lane.
  • commit.js:101-107 does the canonical thing: k.resolveHexAny then keep type==="commit"||"tag"; ~6 lines, no pack re-mmap.

Goals

  • Replace resolveHashlet's body with the commit.js form: k.resolveHexAny(hexish) then k.getObject(sha).type filter.
  • be log:#<commit-hashlet> for a mid-history (non-tip) commit still resolves; an ambiguous prefix still resolves to NOTHING.
  • Remove _packs from the production reader surface (or fence it test-only) so views cannot re-enter the pack walk.

Constraints

  • Byte-equivalent log output: the existing log parity tests (test/js/log/*) must stay green — same resolved sha, same ambiguity → empty behaviour as KEEPResolveHex.
  • Use only the reader's public verbs (resolveHexAny, getObject, resolve.resolveHex tip fast-path); no git.pack in log.js.

WIP

Design decisions

  • Mirror commit.js:101-107 exactly so the two hashlet resolvers converge on the ONE store.resolveHexAny path (see JS-090).
  • log keeps the tip fast-path resolve.resolveHex(k,hexish) first only if it changes no bytes; else fold into resolveHexAny.
