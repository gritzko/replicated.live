JS-038: bin/get.js — be get as a pure-JS extension

Now
DONE

Reproduce native be get as bin/get.js + bin/lib/*, pure JS over JABC (libdog+abc ONLY, no keeper/sniff/graf dog linked), output-equivalent to native across all remotes and change kinds. Validates the wire SDK and extends the JS-027 read-only store reader to the FETCH + write + checkout path.

Input

Context

  • JS-027 proved the read side (be/wtlog/keeper/classify/dag/subs/ignore libs). be get adds the WIRE fetch, pack INGEST (keeper write side), and CHECKOUT (materialise the fetched tree → wt) + REFS/wtlog append.
  • The git-wire conversation lives in keeper/ (unlinkable from JABC), so it is reimplemented in JS exactly as status.js reimplemented sniff.

Goals

  • be get <remote> parity: same op-summary/banner AND same resulting wt state as native, for file://, ssh://(//host), be:// remotes.
  • Change-kind parity: new / del / mod, for both files AND dirs.

Constraints

  • libdog+abc ONLY; jabc link unchanged. Tests in test/js/get/, reusable helpers in test/js/lib/; oracle = native be get. Method: Issues.

WIP

Design decisions

  • Native-leaf prereqs: JS-035 zip, JS-036 delta.encode, JS-037 pack ref.
  • Children: JS-039 wire+pkt+transport (fetch convo), JS-040 ingest (keeper write side), JS-041 checkout + bin/get.js entry. Read libs reused as-is.
