JS-093 jab mis-routes a scheme:<path>.js URI to the script loader

jab diff:view/bro.js (and any scheme: URI whose path tail ends .js) threw require: cannot find 'be/diff:view/bro.js' — the C entry router (js/main.cpp) decided "run as a script vs route to the loop" purely on the .js suffix, so a diff:/cat:/blob: URI ending in .js was loaded as a file instead of dispatched. be diff:view/bro.js and jab diff diff:view/bro.js (explicit verb) worked, isolating it to the URI-shape entry route.

Input

Context

  • Repro: cd ~/journal/be && jab diff:view/bro.js → require error;

    jab diff:main.js same; jab diff:small.c (non-.js) OK; jab diff <uri> OK.

  • js/main.cpp:275 routed JABCEndsWithJs(script_file) first-args to the

    script loader (__runScript/JABCRunFile); a scheme: token never excluded.

Goals

  • A scheme: URI always routes to the loop (__main), even with a .js tail.
  • A bare/relative .js path still runs as a script (no regression).

Constraints

  • C entry only (js/main.cpp); pre-existing, not the BRO-009 diff-colour work.

WIP

Design decisions

  • Add JABCHasScheme(s) — YES iff s opens <alpha><alnum|+|-|.>*: BEFORE any

    / (a URI scheme). Guard the .js script route with && !JABCHasScheme.
