JS-024: git JS package — migrate PACK / delt → git.pack / git.delta

Now: DONE

All git/pack-log JS bindings belong in a git package. MIGRATE (hard cutover, not alias) the existing PACK container and delt.apply — which already wrap dog/git — off abc into git.*. Sets up the home for the pack-log index (the follow-on). Method: Issues.

Input

Context

  • The PACK container (js/cont.cpp, abc.over("PACK") / abc.mmap("PACK")) already wraps dog/git/PACK.c's pack core (per js/INDEX.md) — it is mis-shelved under abc. delt.apply is git delta reconstruction.
  • Session decision: a git JS package for everything git/packlog; *migrate, not alias* (the user's call). sha1/sha256 stay generic.

Goals

  • git.pack(...) — the PACK container constructor + cursor (header/feed/ inflate/resolve/seek/next/count/type/size/baseOffset/ref), moved verbatim from the abc.over/abc.mmap/abc.book "PACK" family.
  • git.delta.apply(base, delta, out) — moved from delt.apply.
  • HARD cutover: REMOVE the abc PACK + delt forms; update js/test/pack.js + INDEX.md / API.md to the git.* surface.

Constraints

  • Pure JS re-home inside cont.cpp (or a new git-bundle): the native _pack_* / _delt_apply leaves are UNCHANGED, just re-exposed under git. No C changes, no new leaves. JABC rule #4 unchanged.
  • The GIT-007 cross-impl vector in js/test/pack.js (a JABC-written log resolves byte-identically through the dog/git OFS_DELTA chase) MUST stay green under the git.pack surface.

WIP

Design decisions

  • (open) git is its own JABC_API_OBJECT (or a sub-bundle in cont.cpp); git.pack is the container builder, git.delta the delta op. Match the existing isLog/build plumbing — PACK is a u8-backed log family.
