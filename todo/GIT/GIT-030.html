jab learns to read OTHER PEOPLE'S git repos in place: mmap their packs and pack indexes, look objects up by sha, never inflate the whole store (what PIDXScan does) and never copy the repo. The API hourglass waist is ODB-only (gritzko, 12Aug26 session): git.open(path) -> handle; git.getHex(h, hexlet) -> {type, bytes} | null; git.getSafe(h, sha40) re-hashes the object before returning; git.close(h). Formats live in dog/git, the stateful handle lives in the jab binding.

Input

Context

dog/git already owns the hard half; what is missing is git's OWN index formats and the handle that composes the pieces.

  • Have: PACKResolve (OFS+REF chase via pack_ref_find), ZINF, DELT, PIDXObjSha, tree/commit parsers, io._mmap.
  • Missing: a pack-*.idx v2 reader, a loose-object reader, refs-from-disk; nothing anywhere parses \377tOc.
  • io._mmap caps maps at 2^31-1 (JABC_MAP_MAX, io.cpp); the linux pack is >2 GiB, so the handle holds NATIVE maps.
  • GIT-021 hit linux-scale reads before (be-store side); this ticket is the foreign-.git twin of that scale.

Goals

One waist, four calls, and a verifier that proves it on real repos up to linux scale.

  • dog/git IDX: idx v2 over a const mapped slice — validate, full-sha lookup, hex-hashlet (6..40) prefix lookup returning the full sha, nth-entry iteration, large-offset table.
  • dog/git loose: drain one loose file (<type> <len>\0 after zlib) with output-full a loud NOROOM, never a wrap (GIT-011).
  • binding git.open(path): .git dir / gitfile redirect, scan objects/pack pairs + objects/info/alternates, native FILEMap (no 2 GiB cap), pack_ref_find over the idx set, one rescan-on-miss, GC finalizer + git.close.
  • git.getHex(h, hexlet) -> {type, bytes} | null (absent); ambiguous hashlet = plain-words throw. git.getSafe(h, sha40) = fetch + PIDXObjSha check; mismatch = loud throw.
  • THE test: a JS verifier reads .git/HEAD (refs parsed in JS, above the waist), walks every commit/tree/blob via getSafe. Ladder: toy repos made by the test with stock git -> mid ~/src repos (git, gitoxide) -> ~/src/linux (6.3G, hours; run only on gritzko's explicit go).

Constraints

  • The waist is ODB-only; refs stay above it, in JS.
  • Reuse dog machinery (PACKResolve, PIDXObjSha, ZINF, DELT) — no parallel resolvers, differs or hashers.
  • dog/git stays caller-scratch, allocation-free; ownership, malloc and maps live in the binding (io.cpp precedent).
  • v1 non-goals, refused loudly where reachable: SHA-256 repos, idx v1, reftable, MIDX (per-pack idx suffices), commit-graph, delta-base cache, .rev files.
  • Errors in plain words at the JS boundary, never ok64 codes.

WIP

Design decisions

  • Handle in the binding, formats in dog — keeps JABC rule #4 for dog code while the handle owns maps + scratch.
  • Miss policy: one objects/pack rescan + loose retry, then null — a live repo gains packs under a long-lived handle.
  • Prefix lookups return the matched full sha so the binding can dedup the same object across packs vs true ambiguity.
  • RULING 12Aug26: v1 follows NO alternates — info/alternates present = loud ODBALTS refusal; one objects dir (commondir).
  • RULING 12Aug26: loose fan-out dirs = u64 fan[4], one bit per dir 00..ff; refreshed by the one miss-triggered rescan.
  • RULING 12Aug26: pack identity = u64 hashlet, the leading 16 hex of the pack-<40hex>.idx name; other idx names skipped.
