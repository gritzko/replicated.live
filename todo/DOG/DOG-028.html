StrictMark was restructured 2026-08-12: one continuation law (block content one quad deeper, dedent ends it), a block-element table, fewer special cases. The C lexer implements the old reading in four places. The fence-closer part is already staged in the //fence-closer/ worktree (dog/tok/MKDT.c + dog/test/TOK01.c repro cases, ctest 119/119 green) — this ticket continues in that worktree.

Input

Context

MKDTLexer (dog/tok/MKDT.c) drives .mkd tokenizing for render, diff and the pager; the spec StrictMark is the truth. Staged already: optional depth-aware fence closer — deeper fence run is body, dedented opener chains snippets, bare closer at opener depth is a consumed no-op.

Goals

  • Captioned rulers: ---- caption is a ruler, the caption is its rest; the dash run stops at four — a 5th dash makes the line a paragraph, never a ruler captioned with dashes.
  • Ruler captions, header text, ref def url/title, meta values continue one quad deeper (joined), per the one continuation law; today each leaf lexes its marker line only.
  • Legacy 3-char short forms (3-backtick fence, 3-dash ruler) stay accepted on read.
  • Repro-first: TOK01 tag-string cases for each new behavior, failing before the fix.

Constraints

  • Grammar shape changes go in dog/tok/MKDTB.c.rl (regen: ragel -C MKDTB.c.rl -o MKDTB.rl.c -L); derived facts stay stateless inquiries in MKDT.c (DOG-026), no hand-rolled byte scanning.
  • No existing tests edited; new cases/functions only; full ctest green.
  • ABC idioms per abc; comments max 2 lines, start with DOG-028.

WIP

Design decisions

  • hrule mark confirms on the first non-dash byte via the staged hr_run/hr_set actions; the rest becomes the caption.
  • Leaf continuation reuses the paragraph-run discipline (want_quads/want_quotes) with a per-leaf content mode: inline (header, ruler caption), verbatim (ref def, meta value).

Blockers and bummers

Outcome

Implemented in the //fence-closer/ worktree: dog/tok/MKDTB.c.rl (+regen), dog/tok/MKDT.h, dog/tok/MKDT.c, dog/test/TOK01.c — 5 files staged, not committed. Suggested commit: DOG-028: ruler captions, leaf continuation in MKDT.

  • hrule confirms on the first non-dash byte or end of input; ---- with no trailing newline is now a ruler; 5+ dashes stay a paragraph.
  • Ref def continuation is inline-mode, not verbatim: the spec table says url/title text and the DOG-024 case [1]: url runs the inline layer.
  • A deeper line carrying its own marker ends a leaf run, paragraph-style; only the fence swallows markers as body.
  • Leaf and paragraph now share one driver path; content sits one quad deeper than ANY marker (want_quads +1, list or leaf).
  • Full ctest 119/119; wiki/StrictMark.mkd and this ticket smoke-lex clean through the new build.
