DOG-023: jab binds no read-only ULOG open, tail, or ts-seek — JS reads bypass the wh128 sidecar entirely

Now: OPEN

jab/ulog.hpp boxes a native ULOG as a handle and binds _ulog_open/_append/_count/_rowUri/_rowTime/_close (:347-361), but _ulog_open is ULOGOpen — always RW/booked. There is no ULOGOpenRO, no ULOGHead/ULOGTail, no ULOGSeek/ULOGFind, and no _ulog_rowVerb, so a row cannot even be fully read through a handle. Consequently every JS reader (shared/ulog.js each/drain) skips the handle, raw-mmaps the file and walks it linearly — the wh128 sidecar index the log maintains is unused on every read. Bind the missing read leaves. Scope is jab ONLY; the JS consumer cut-over is a separate ticket in the be tree.

Input

Context

  • Bound today (jab/ulog.hpp:347-361): _ulog_open (RW ULOGOpen, :271), _ulog_append, _ulog_count (:310), _ulog_rowUri (:320), _ulog_rowTime (:331), _ulog_close, plus the stateless codec family.
  • The stateless leaves (_ulog_feed/next/time/verb/uri/ seek{Verb,Time,URI}) work over a JS buffer at an offset — NOT over a native handle.
  • Unbound in jab/dog/ULOG.h: ULOGOpenRO (:184), ULOGSeek (:230), ULOGFind (:233), ULOGHead (:236), ULOGTail (:241).
  • A reader must therefore open RW (booking + trim on close) or bypass the handle — shared/ulog.js:42-56 picks the bypass.
  • Cost downstream: nowAfter(tail) callers drain the WHOLE log to read one tail ts.

Goals

  • A JS reader can open a ULOG read-only, ask its row count, read any row's ts/verb/uri, and get head/tail in O(1) — without booking or trimming the file.
  • A ts lookup goes through the wh128 sidecar (ULOGSeek/ULOGFind), not a linear scan.
  • Open-read-close is the shape: a handle is acquired, read through, and closed — no map outlives the scope.

Constraints

  • jab tree ONLY (jab/ulog.hpp, jab/test/, jab/INDEX.md, jab/API.md). Do NOT touch the be JS tree or dog/ULOG.c — bindings, not new C.
  • Pure marshalling leaves, matching the file's existing style (INDEX.md:91: "pure-marshalling native leaves").
  • ron60 crosses as a BigInt (API.md:328) — keep the existing ts marshalling, do not invent a second form.
  • An RO handle must refuse append and must not trim on close; RO and RW handles share one box type.
  • MEM-016 (DONE) fixed an unbook leak on the ULOGOpenRO scratch-alloc path — do not reintroduce it in the box.

WIP

Design decisions

  • New leaves: _ulog_openRO, _ulog_rowVerb, _ulog_head, _ulog_tail, _ulog_seek, _ulog_find. Names mirror the ULOG.h entry points.
  • Handle box carries an ro flag; _ulog_append on an RO box throws, _ulog_close skips the trim.
