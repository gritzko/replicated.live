Context

PACKResolve (dog/git/PACK.c) re-inflates the WHOLE delta chain on every read: chase to the chain root, inflate it, apply every delta back up — nothing is remembered between calls. The lite indexer reads each commit's trees right after its parent's (topo order), so the same bases are re-inflated hundreds of times. Measured on git.git (81,726 commits): getHex ~71us/call over 246k calls = 17.5s of a first index; linux delta chains are deeper, so the factor there is larger. git core solves exactly this with delta_base_cache (packfile.c, 96MB LRU keyed by pack+offset). With DOG-030's getTreeDiff reading trees inside the C leaf, this cache serves those reads for free.

Goals

One cache in the odb struct — the delta-base cache and the tree-object cache are the SAME table (ruled plan, 2026-08-13).

  • Key (pack, offset), value inflated bytes + type. PACKResolve consults it at EVERY hop of the chase, so a chain resolves from the nearest cached hop, not the root.
  • Filled on the way back up: each intermediate apply result lands in the cache; the requested object's own offset is hop 0, so a repeated whole-object read is a straight hit, zero inflates.
  • Byte-budgeted, default 64MB; trees + commits only (blobs are read once in our workloads and would flush the budget); oversize objects (>1MB) skipped.
  • Eviction: FIFO ring arena + fixed slot table first (no per-entry malloc); measure vs LRU and only add list bookkeeping if the numbers ask for it.
  • Per-handle, single-threaded, freed in ODBClose.
  • Target: getHex 71us -> 10us on the git.git probe; parity — cached and uncached reads return byte-identical objects (ODBSafe re-hash stays green over a large sample).

Constraints

  • All inside dog/git (ODB.c/PACK.c/ODB.h); no JS surface change, no binding change — the cache is invisible above the waist.
  • ABC idioms (meta/abc.mkd): typed slices/buffers, no pointer-arithmetic escapes; cache memory owned by the odb struct (a buffer implies ownership), not BASS (it must outlive call() frames).
  • DOG-014 (PACKResolve ping-pong sizing) owns that invariant — do not entangle; repro-first, ctest green, no other tests edited.

WIP

Design decisions

  • (pack, offset) not sha: mid-chain hops have no sha without hashing; offsets are what the chase walks.
  • Cross-pack REF_DELTA hops key by the pack the finder resolved to.
