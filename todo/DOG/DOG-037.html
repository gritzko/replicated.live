gritzko's ruling 2026-08-15: plain text SHOULD include the LINK grammar. DOG-036 deliberately left dog/tok/TXTT.c.rl unwired ("that would newly fuse refs in plain text, which nobody ruled") — now it is ruled. TXTT lexes .txt, .rst and every unknown extension (the TOK.c:359 fallback), so this lands fused F refs in all prose-shaped files at once; .rst later moves to its own machine per DOG-038.

Input

Context

  • TXTT.c.rl is a 3-rule word/space/punct splitter: no include LINK, no F emit path, tags hardwired to 'S'/'P'.
  • Dispatch: E("txt", TXTTLexer) E("rst", TXTTLexer) (dog/tok/TOK.c:210-211) plus the unknown-ext fallback if (fn == NULL) fn = (TOKfn)TXTTLexer (TOK.c:321 area, line 359).
  • The binding model is FREE.c.rl: FREEEmitPathRef gates a bare name on TOKPathRefKnown, retreats via TOKSplitText; anchors cap at 10 chars (TOKUNCUT, DOG-034).
  • DOG-036 pins the accepted/rejected shapes (GPL-2 prose, abc/Makefile:20 fuses) — those rulings apply verbatim in plain text.

Goals

TXTT pulls include LINK "LINK.rl"; and binds the same rule set as FREE — ticket, relknown (KNOWN-ext gate), dirs relanch, rooted, the keyed code-heads-path forms — emitting one fused 'F' per accept; every non-link byte tokenizes exactly as today.

  • .txt, .rst and unknown-ext files all get clickable F refs in lite/bro.
  • TOK01-style fixtures: the DOG-036 positive/negative table rerun through TXTT.

Constraints

  • Grammar via the ragel include only; never ever manual parsing in C.
  • Repro-first: fixtures land before the grammar change; regenerate the twin ragel -C TXTT.c.rl -o TXTT.rl.c -L; ctest -j16 clean.
  • No TXTT behavior change outside link fusing — word/space/punct tags stay.

Blockers and bummers

  • JABCbass (CMakeLists.txt:165, TIMEOUT 10) now overruns at 10.6s (was 6.3s). Not a behavior clash — a BUDGET clash. test/bass.js:24 folds a 256 KB blob 1200x with ext "txt", so the whole loop runs through TXTTLexer, and the LINK grammar costs plain text 68.3 -> 40.4 MB/s (1.69x, measured on that exact blob). That is simply what the shared grammar costs: FREELexer measures 31.6 MB/s on the same input, so .txt now folds at the same price .mkd, .md and every commented source file already paid. Needs a ruling — I may not touch another ticket's test. Options: raise the timeout, drop the iteration count (its comment pins 1200 as "headroom over 960", so 1050 still catches the JAB-008 leak), or accept plain text is now a prose machine and re-tune. Everything else is green.

Outcome

Landed in //DOG-037-quickjab/, sub //DOG-037/dog#eba7baf6 (staged, not committed): dog/tok/TXTT.c.rl pulls the shared grammar and binds the same five rules FREE does, so .txt, .rst and every unknown extension fuse F refs. No new tag, no tok32 change, no manual byte scanning.

  • dog/tok/TXTT.c.rl 73 -> 139 lines: include LINK "LINK.rl"; inside machine TXTT, the five rules verbatim from dog/tok/FREE.c.rl:174-180 (ticket => on_key, code keyvoid => on_nokey, dirs relanch | rooted | code "/" relanch => on_anchored, relknown | code "/" relknown => on_pathref, dotdot => on_dotdot), listed ABOVE the word/space/punct rules so longest-match still decides and the anchored rule wins the tie on src/weird.xyz:12. New helper TXTTEmitPathRef (dog/tok/TXTT.c.rl:7) is FREEEmitPathRef with TXTT's tag: TOKPathRefKnown -> 'F', miss -> TOKSplitText('S', ...). TOKUNTAIL / TOKUNCUT carry the DOG-034 10-char cap exactly as in FREE.
  • Twin regenerated with ragel -C TXTT.c.rl -o TXTT.rl.c -L, 248 -> 1002 lines, never hand-edited. dog/tok/TOK.c untouched — the E("txt"), E("rst") rows and the TOK.c:359 unknown-ext fallback all reach the rewired machine as they are (DOG-038 owns that file).
  • TXTT keeps its own tag vocabulary — 'S' word, 'S' whitespace, 'P' per other byte. It has no number and no hi-byte rule, so the DOG-036 table answers with TXTT crumbs where FREE answers 'W'/'L': localhost:8080 -> SPPPPP (FREE SPL), 12:30 -> PPPPP, file.c:12345678901 -> F + 12 P. The ACCEPT set is identical.
  • The retreat paths do move crumb boundaries, unavoidably and exactly as FREE does it: a look-alike that entered a link rule comes back out through TOKSplitText, which groups alnum runs. example.com:443 was SPSPPPP, now SSSSS; ISO-8859-1 was SPPPPPPP, now SSSSS. Tags stay inside TXTT's {S,P} vocabulary; only bytes that reach a link rule are affected.
  • Fixtures: TXTTNavTest (72 cases) + TXTTPlainTest (9 cases) in dog/test/TOK01.c:1354 and :1447, the DOG-036 accept/reject table plus a guard that ordinary prose (hello world, x = 42;, The quick brown fox.) tokenizes byte-for-byte as before. 48 of the 72 nav cases were RED against the pre-change lexer, all 81 green after.
  • ctest -j16: 121/122 pass, TOK01test among them; the single failure is the JABCbass timeout above, which was 122/122 green on the untouched clone.
