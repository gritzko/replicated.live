Input

Context

Evidence: refs planted in ~/src/linux/include/drm/drm_exec.h (min_addr.c:30:20, min_addr.c:ES:LjJu …) — every form opens on the right line, none selects the token.

  • _land maps land.line to the line's FIRST display row and stops; with wrapping, the col's byte may sit rows further down.
  • LITE-025's forward map names the exact token covering the anchored byte at the head rev, then hands the door only {line, col} — the pager re-derives nothing.
  • LITE-023 cursor model: cur.tok indexes a token within the display row; the stronger token wash renders it.

Goals

Landing puts the cursor ON the token, for both link forms; bare :line stays a line landing.

  • :line:col — select the token covering byte lineStart + col - 1; the cursor row is the display row that CONTAINS that byte, not the line's first wrapped row.
  • Permalink — the resolver's own token comes through the door and is selected; no col round-trip re-derivation.
  • Bare :line — active line only, tok: -1, unchanged.
  • Col in a token gap or past the line end — land on the line (tok -1), never guess a neighbor.

Constraints

  • ///lite worktree only; no VC ops.
  • Rides the LITE-023 cursor/wash — if 023 has not landed first, this ticket waits (On1).
  • Verify through the real UI path: pty probe follows :line:col and a permalink, asserts the token wash sits on the target token, wrapped-line leg included.

Spec/code notes, nothing improvised around:

  • A pushed view ALWAYS opens no-wrap (setHunks hardcodes wrap:false), so a landing never happens on a wrapped view; and no-wrap clamps a row at the right edge, so a column past it belongs to NO display row. Both are served by the cursor keeping the token's BYTES: the landing seats on the line's row and the first re-index (a W, a resize, a pop) seats it on the row that holds the byte. If landings should instead open wrapped, that is a ruling.
  • "A col in a token gap" — the tok stream TILES the text, there are no holes; the rule is spelled as the byte being whitespace, or its token tagged W / hidden (U/O). Punctuation is a token and gets selected.
