WIP

Design decisions

Confirmed against the code; the format-v2 body is CHAT-001's verbatim, only the be-isms are bridged.

  • Verb body lite/index/chat.js exporting {chat}, main.js runChat wrapper on the verb line before the --plain scan — the LITE-014 merge/install wiring exactly.
  • shared/util/path.js gave chat only dirname + resolveInTree; both inlined (7 lines), the resolver as index/log.js's textual normalize. Model difference: a .. above / clamps instead of throwing NAVESCAPE — lite has no worktree to escape from.
  • be.ctxDir() → io.cwd(): lite has no context dir, every path arg already counts from the cwd (index/log.js, index/merge.js).
  • quickjab's io.log appends the newline itself (jab's does too, so be's report lines are double-spaced); lite's say() passes no trailing \n — the ONE deliberate departure from CHAT-001's call sites, and it only makes the report tighter.
  • throw "CHATNONE" → the plain-words throw index/merge.js uses ("errors in plain words"); the io.log + code pair was be's convention, not a format ruling.
  • ZERO quickjab edits needed: io.{log,readdir,mkdir,stat,mmap,open,buf,writeAll,close,getenv,cwd}, utf8.{Encode,Decode}, Date local time under $TZ and the RegExp constructor all behave as chat.js assumes (probed on the tree-built binary). io.readdir marks dirs with a trailing /, which the *.jsonl filter drops anyway.
  • Tests: ONE test/chat/run.sh with three legs (render/append/strict), as test/merge/run.sh carries its three — same fixtures, same expected bytes, lite's ok/bad counters. $CLAUDE_CONFIG_DIR per leg points at that leg's scratch Claude home; HOME is a fake, so nothing reaches the real ~/.claude. Dropped: CHAT-001's strict leg part (7), the jab mark render check — lite has no mark verb.
  • No lite/jsrc symlink was needed and none was made: -DQUICKJAB_JSRC_PACK=ON packs the tree into the binary, so the fixture dirs run the packed floor from any cwd.
