Found on /cat/Documentation/security/credentials.rst (gritzko, 2026-08-15; fix ordered in the main lite/ tree, served page rebuilt+verified). Kernel reST indents list items with one space, bodies with five, nested bullets with a TAB — docutils reads a tab as an 8-column stop, mark/rst.js counts it ONE (the v1 note in LITE-037), so every tab-indented sub-list falls out of its enumerated item and the <ol> splits into ol / ul / ol start=N fragments. Separately, listAt lays the marker-line text at column 0 while the item's continuation keeps its extra indent, so dedent never fires and every item body wraps in a spurious <blockquote>.

Input

Goals

  • Tabs expand to 8-column stops before parsing, docutils' input rule, so nesting reads as the author saw it; literal blocks carry the expanded spaces, as docutils' do.
  • An item's body dedents on the CONTINUATION lines' own common indent, the marker-line text folded in front — a body deeper than the marker no longer re-quotes; a run deeper than the body still does.

Constraints

  • Repro checks in test/rst/run.sh first; mark/rst.js only; existing checks stay.

WIP

TODOs

  • rebuild build-release, reinstall ~/bin/lite, restart serve, re-read the pages

Outcome

Fixed in the main ///lite/ tree (ordered), working-tree edits, nothing put or posted; build-release rebuilt, ~/bin/lite reinstalled, serve restarted on :8888.

  • mark/rst.js: detab expands tabs to 8-column stops at parse entry (docutils' input rule, mark/rst.js:36); listAt dedents the item body on the CONTINUATION lines' own indent with the marker-line text folded in front (mark/rst.js:222); quoteAt unwraps a block quote holding nothing but lists — indentation-as-layout, no quote bar — while indented PROSE keeps the quote (mark/rst.js:127); a field list renders one <p><strong>Name:</strong> value</p> per field, value inline-parsed with indented continuation folded (fieldAt, mark/rst.js:180; overrides LITE-037's plain-text degrade, ruled by gritzko on digsig.rst).
  • test/rst/run.sh: +7 checks, 81 total, all green; whole suite at baseline parity (diff/pager pre-existing); all 3989 kernel .rst files through the parser, 0 throws.
  • Live pages verified over HTTP: credentials.rst is one continuous <ol> 1..7, tab bullets nested inside their items, no quote bars on lists (the a./b. DAC/MAC indented prose still quotes, as reST reads it); digsig.rst and lsm.rst carry Author:/Date: as bold pair lines.
