Beagle-lite (lite) is the quickjab single-binary beagle for plain git repos; its jsrc tree is the packed floor. First slice: the file pager must display files with syntax highlighting. This ticket ports the SHARED render lib — hunk build, row index, THEME paint — from be/, with every be-specific pass removed. Syntax file/dir view only.

Input

Context

The be/ originals to port from (READ-ONLY, never edit them): be/view/bro.js (the render lib) and be/view/theme.js (the palette). The runtime bindings (io, tok, utf8, tty) are identical under jab and quickjab (quickjab/*.c port them 1:1; see quickjab/PORTING.md).

  • A hunk is {uri, verb:"hunk", text:Uint8Array, toks:Uint32Array, kind}.
  • tok32 layout: 31..27 tag A+n, 26 custom, 25..24 side, 23..0 end offset; tok.parse(bytes, ext) fills it.
  • The ansi64 model + deltaSGR speller (view/bro.js A0/aOr/deltaSGR/resetSGR) is the ONE SGR emitter — keep it verbatim.
  • Never read beagle/; the C reference is not needed for this port.

Goals

Create lite/view/bro.js and lite/view/theme.js: the trimmed ports. Export names stay IDENTICAL to be/'s so the pager port (LITE-002) maps 1:1.

  • KEEP in view/bro.js: TOK_TAG/TOK_END, UTF8_LEN cell walk, THEME table (syntax tags D/G/L/H/R/P/N/C/F/T + defaults), themeAt, ansi64 (A0/aFgB/aFg256/aFlag/aOr/aEq), deltaSGR/resetSGR/feedColor, cellAnsi (PASS_NORMAL/side-EQ only), rowEnd, indexRows (wrap AND no-wrap), buildFileHunk, buildDirHunk, fsPath, pathExt, statusPos, plainHunk, THEME_BANNER + bannerColor.
  • statusURI simplifies to plain string concat <path>#L<n> — lite has NO URI machinery; a pathless hunk shows its uri verbatim.
  • Keep the U/O-hidden-cell discipline in the walks (cheap, keeps the loops byte-identical to the original; lite just never produces them).
  • KEEP in view/theme.js: SLOTS_16 syntax tags, makeTheme, BANNER_SGR + bannerOpen/bannerClose + loadOpen/loadClose aliases, select/DEFAULT.
  • DROP everywhere: the diff two-pass renderer (sides, walkHunk, classifyLines, paintDiffRow, hasDiffSides, DIFF_WASH), why/blame (O-origin colours, paintWhyRow, whyPlain), elastic B (elasticRow/Pad/Clip), TLV/table/HUNK-log renderers (buildTableHunk, tableHunk, renderHunkLog, abc.ram), VERB_SLOT status verbs, QUAD_SGR, BTN* palettes, pale().

Constraints

  • Pure JS over the quickjab-shared bindings only: io, tok, utf8, tty. NO uri/URI, NO abc, NO require of be/ files — the lite tree is self-contained.
  • Touch ONLY lite/view/bro.js and lite/view/theme.js. No other file, no VC ops, no commits.
  • Verify from a cwd inside lite/ with BOTH runtimes: jab <probe.js> and quickjab/build-lite/bin/quickjab <probe.js> (probe scripts live in ~/tmp; bareword requires resolve via the lite jsrc scan).
  • Size target: bro.js well under 400 lines, theme.js under 100.

WIP

Design decisions

  • THEME16 (the legacy 16-colour STRING table) + cellSGR are NOT ported: they are absent from the KEEP list, and be's only remaining references to them are comments — BRO-010 moved the pager onto cellAnsi → deltaSGR. The ansi64 THEME is the one table.
  • The ported THEME carries W (whitespace, green) on top of the listed syntax tags D/G/L/H/R/P/N/C/F/T: buildDirHunk itself emits a W tag on each entry's '\n', so dropping the slot would leave lite producing a tag with no entry. Every other slot (diff bg I/O/J/K, quad, buttons) is gone.
  • cellAnsi(tag) takes ONE argument (PASS_NORMAL / side EQ is the only combination lite has). be's pager calls bro.cellAnsi(tag, 0, 0) — the extra args are simply ignored, so the LITE-002 call site still maps 1:1.
  • statusURI accepts a hunk OR a bare path string, and returns the uri verbatim when it is empty. With no URI parser there is no "pathless" test to make: a lite hunk uri IS a filesystem path, so the anchor is a concat.
  • lite/view/bro.js does NOT require theme.js (be required it only for DIFF_WASH). The two lite modules are independent: bro owns the ansi64 table the renderer paints with, theme owns the SGR-string table.
  • Exports keep be's spelling; bannerColor, THEME_BANNER and themeAt are exported although be keeps them module-private — in be they are reachable through the diff/why renderers, which lite drops, so without the export they would be dead code. Everything else is be's export list minus the dropped machinery.
  • The walks (rowEnd, indexRows, bannerColor, plainHunk, both hunk builders) are copied byte-for-byte including the U/O hidden-cell skips; only the elastic-B branch was cut out of the wrap === false arm.
  • PROBE PLACEMENT: jab pins its jsrc stack by climbing from the MAIN SCRIPT's directory, not from $PWD — a probe in ~/tmp climbs to $HOME/jsrc -> be and silently loads be/view/bro.js. The probes therefore live in ~/tmp/lite-probe/ with a jsrc -> …/lite symlink beside them (cwd stays lite/, so the relative main.js / . args still hit lite).

Outcome

Both files created, nothing else touched, no VC op run.

  • lite/view/bro.js — 276 lines (target: well under 400). TOK_TAG/TOK_END, UTF8_LEN, the ansi64 model (A0/aFgB/aFg256/aFlag/aOr/aEq), the syntax THEME + themeAt + THEME_BANNER, feedColor/deltaSGR/resetSGR, cellAnsi, bannerColor, fsPath/pathExt, buildFileHunk/buildDirHunk, rowEnd/indexRows (wrap + no-wrap), statusURI/statusPos, plainHunk.
  • lite/view/theme.js — 99 lines (target: under 100). SLOTS_16/DARK/LIGHT (syntax tags only), BANNER_SGR, makeTheme (paint/reset/bannerOpen/ bannerClose/loadOpen/loadClose), THEMES/DEFAULT/select.

Probes (~/tmp/lite-probe/, cwd lite/), both runtimes, identical output:

  • probe.js — 35 checks, ALL OK under jab and under quickjab/build-lite/bin/quickjab: buildFileHunk("main.js") toks nonempty + hunk shape, pathExt/fsPath, plainHunk bytes exact (hunk main.js\n + file bytes + NL iff missing), indexRows cols=40 wrap=true soft-wraps a 300-char line into 8+1 rows / wrap=false clamps to 1 row per line, rowEnd codepoint-safe on multibyte + skips U cells, a painted row carries ESC[ and ends ESC[0m, the comment row opens ESC[90m (tag D), the bold (1/22) and 256 (38;5;56) deltas, the banner band byte-for-byte, buildDirHunk(".") listing with one F tag per entry and view/ keeping its slash, statusURI("a/b.c",7)=="a/b.c#L7" + the hunk form, statusPos ALL/TOP/BOT/50%/exact-fit, and the theme paint/reset/banner/select/ makeTheme surface.
  • parity.js — lite vs be/view/bro.js on 5 targets (main.js, view/bro.js, view/theme.js, README.mkd, the .github dir) × cols 40/80/200 × wrap true/false: hunk text+toks identical, plainHunk bytes identical, indexRows row spans identical (and be emits no els for these), every row's painted string identical, statusURI/statusPos identical. PARITY OK under both runtimes.

Deviations from the ticket: none in scope. Two judgement calls are recorded under Design decisions — the W whitespace slot kept in THEME (buildDirHunk emits that tag), and bannerColor/THEME_BANNER/themeAt exported (they would be dead code otherwise). cellSGR/THEME16 were dropped as not-on-the-KEEP-list.
