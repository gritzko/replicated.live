LIST — the list: github-style directory view

list:<path> is a NEW read-only VIEW: a github-style directory browser that FUSES the working-tree listing (ls's classify) with each entry's LAST COMMIT (message + short relative age), files AND dirs, one row each. It is the friendly counterpart to the technical tree: (raw mode/type/sha40) and the cheap wt-only ls: (verb + mtime) — neither carries a commit message, so list owns the one expensive fuse (the per-entry last commit via a bounded history walk), kept in its own view so ls/tree stay O(dir). Pure jab+libdog bindings + JS, NO dog binary. Method: Issues.
