DIFF-012 MED: jab diff (no args) shows NOTHING — source the dirty file list from the classifier

jab diff with no path arg prints nothing even when the worktree has uncommitted changes, while native be diff prints the full working-tree-vs-baseline diff. The no-arg (whole-wt) form is the broken one: jab diff <path> emits fine. be status correctly reports the dirty file, so the classifier sees the change; only the no-arg diff: render fails to enumerate it. The fix is to drive the no-arg file list from the CLASSIFIER (classify.js, the same authority status and bare put use), then diff each dirty tracked file vs its baseline. be/ JS diff: view (reported by user, 2026-06-30; live repro in ~/todo/GET-037).
