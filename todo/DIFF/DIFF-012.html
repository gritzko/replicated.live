DIFF-012: jab diff (no args) shows NOTHING — source the dirty file list from the classifier

Now
DONE

jab diff with no path arg prints nothing even when the worktree has uncommitted changes, while native be diff prints the full working-tree-vs-baseline diff. The no-arg (whole-wt) form is the broken one: jab diff <path> emits fine. be status correctly reports the dirty file, so the classifier sees the change; only the no-arg diff: render fails to enumerate it. The fix is to drive the no-arg file list from the CLASSIFIER (classify.js, the same authority status and bare put use), then diff each dirty tracked file vs its baseline. be/ JS diff: view (reported by user, 2026-06-30; live repro in ~/todo/GET-037). Spec Verbs / Projector; method Issues.

Input

Context

  • Repro (in ~/todo/GET-037, a worktree carrying mod verbs/get/get.js): be diff (native) prints the 85-line wt-vs-baseline diff; jab diff prints NOTHING (empty, exit 0).
  • Both jab diff (bareword) AND jab ~/todo/GET-037/main.js diff (the worktree's own entry) are empty → NOT a stale-locator (GET-036); a real diff: view bug.
  • jab diff <path> (named) emits — it is NOT broken. (Its WHOLE-FILE output — jab 933 lines vs native 932 for a 924-line file — is the single-file full-file mode shared by BOTH binaries, tracked separately in DIFF-005; NOT a jab bug.)
  • be status reports mod verbs/get/get.js, so the change IS classified — only the no-arg diff fails to enumerate the dirty set.
  • Candidate cause: views/diff/diff.js (the diff: handler, JS-071) RE-PARSES its spec off ctx.args[0]; diff is NOT in core/resolve.js VIEW_REPARSE, and a no-arg jab diff seeds a synthetic . row with EMPTY ctx.args, so the no-range wt-vs-baseline whole-wt branch (diff.js ~358-408) never enumerates the dirty files.
  • Native be diff (no args) shows the wt-vs-baseline diff — the JS port diverges.

Goals

  • jab diff (no args) prints the working-tree-vs-baseline diff of every dirty tracked file, matching native be diff.
  • The dirty file list comes from the CLASSIFIER (classify.js), not a bespoke walk — one source of truth for "what changed", shared with status and bare put.

Constraints

  • be/ JS only. REUSE classify.js for the dirty set + the existing per-file diff path in diff.js; do not re-roll a separate wt walk. Keep the friendly throws.
  • Repro-first (CLAUDE §17): a dirty wt where be diff shows changes but jab diff shows nothing (self-contained; ~/todo/GET-037 is a live example).
  • Do NOT regress the working forms: diff:<path>, diff:?branch, diff:?a..b range, and the sub-aware forms. The single-file whole-file behaviour is DIFF-005's call, out of scope here.

WIP

Design decisions

  • No-arg jab diff enumerates the dirty set via the classifier (classify.js — the mod/new/del/mov buckets), then renders each path through the existing per-file wt-vs-baseline diff. Same classifier authority status and bare put use.
  • Wire the seed so the no-arg form reaches that branch: add diff to core/resolve.js VIEW_REPARSE, OR default the handler to the wt-vs-base spec when ctx.args is empty (the . placeholder row) — match how log/commit/tree reparse.
