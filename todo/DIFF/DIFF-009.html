DIFF-009: tree diff silently drops files — 1-2 headers on Ubuntu CI, once ALL headers locally — exit 0 either way

be diff:?v1..v2 (test be-diff-17-tree-no-truncate, 80 modified files) intermittently emits fewer file diffs than it should, with exit 0. Two observed signatures: (A) Ubuntu CI drops 1-2 MID-LIST headers with the tail intact (2026-07-06 run 28809192096: 79/80, highest header f079 present; earlier runs: 2 dropped); (B) once locally (musl, default build): tree.got.out entirely EMPTY, still exit 0. Local hammering never reproduces A (33 runs green across gcc/clang x default/Release, then 20 more). A partial fix is drafted (see WIP). Related: DIFF-007 "diff:<largefile> silently empty" (the silent-empty family), DIFF-008 (the per-file BASS rewind this test guards).

Input

Context

  • CI evidence (logs_77867460502.zip, ubuntu job): FAIL: 79 / 80 file headers present, highest header: --- a/f079.txt, last-12-lines tail complete — so ONE file among f000..f078 emitted nothing; runner scratch not preserved.
  • Since DIFF-008, the per-file GRAFDiff2Layer is call()-propagated (graf/DIFFREF.c:600) — a per-file FAILURE cannot silently truncate anymore; the only remaining silent-skip paths in the loop are the two soft-guarded KEEPGetExact reads (graf/DIFFREF.c:571-584): ANY non-OK read left a side empty, and empty-vs-empty renders nothing — one dropped file, exit 0.
  • Signature B (local, once): the whole diff empty with exit 0 — upstream of the per-file loop (ref resolve / set build / output path), undiagnosed; smells like DIFF-007's family.

Goals

  • No silent drops: a read/render failure inside a tree diff either fails the verb loudly or renders an explicit placeholder — never exit-0-with-missing-files.
  • Signature A gone on Ubuntu CI (watch the next runs); signature B reproduced or bounded (keep tree.got.out + stderr on failure — the test already keeps scratch).

Constraints

  • Do not regress the legitimate soft cases: KEEPNONE (absent object) and non-blob types still soft-skip a side; only genuine ERRORS propagate.
  • Repro-first where possible; signature A has no local repro, so the CI runs ARE the verifier for the drafted guard.
