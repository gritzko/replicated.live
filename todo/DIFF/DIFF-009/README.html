DIFF-009: be-diff-17 drops 2 file headers on Ubuntu CI only

be-diff-17-tree-no-truncate fails on the Ubuntu runner (78 / 80 file headers present) yet passes 0/55 locally (25 plain + 30 under 8× CPU stress), same Release build. Two CI runs hours apart are byte-identical (ci-fail.log) — DETERMINISTIC, not a flake. NOT the DIFF-008 tail truncation this test guards: the last file f079 is present, be exits 0, empty stderr, no BASS NOROOM. Two MID-LIST files lose their --- a/fNNN header — likely --- /dev/null adds the grep '^--- a/f' misses. Method: Issues.

Goals

  • Determine WHICH 2 files and WHY they lose the --- a/f header on the runner; make the tree diff emit all N file headers deterministically across platforms/filesystems.
  • If they render as --- /dev/null adds → from_set missed them (collection/order bug); if absent → skipped sha-equal at :560 (v2 staged stale blobs). Pin which.

Constraints

  • Reproduces only on the runner; needs the CI-kept scratch (…/diff/17-tree-no-truncate, tree.got.out). graf change gates for review; keep small-set output byte-identical.
