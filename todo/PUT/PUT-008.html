PUT-008: bare jab put ignores the cwd/nav dir context — stages the WHOLE tree + every mounted sub

Now
OPEN

Input

Context

Reported by gritzko 2026-07-11: a bare :put typed in a wiki-navigated pager view (footer put ///wiki) staged todo/README.mkd, all of wiki/* AND beagle/mark/* inside the beagle sub — the whole tracked-dirty set, sub banners and all.

  • Repro'd in a scratch clone: bare jab put from shared/ staged root-level CMakeLists.txt + README.mkd and descended the test sub; the cwd never scoped anything.
  • Root cause: verbs/put/put.js putRun with no path args runs bareStage(repo,…) + bareStageSubs (PUT-004/SUBS-044) over the whole wt; be.ctxDir (BE-032) is never consulted; the loop's BE-048 block deliberately left mutations whole-scope — gritzko now extends the ruling: a DIR context scopes a bare mutation too (git parity: git add -u in a subdir is cwd-scoped).
  • Explicit jab put <dir> already scopes correctly (verified) — regression-guard it.
  • View-side siblings, same class, landed 2026-07-11: STATUS-006 + DIFF-013 — reuse their discover.ctxSub helper (exported by that fix).
  • Found mid-diagnosis, own ticket: BE-049 — a ///path mutation arg0 rescopes to the OUTERMOST repo from a nested worktree (do NOT fix here).

Goals

  • Bare jab put from a subdir cwd (or a pager context nav'd into one) stages only the tracked-dirty set under that dir; from the wt root, unchanged whole-wt.
  • Sub recursion (bareStageSubs) descends only mounted subs AT/BELOW the scope dir.
  • A scoped bare put with nothing eligible refuses PUTNONE as today — never a silent whole-wt stage.

Constraints

  • Repro test first (work); fix in beagle-ext (JS); minimal diff; no edits to unrelated tests.
  • Reuse discover.ctxSub (the STATUS-006 mechanism), one shared shape — no per-verb reimplementation.
  • Mutations are dangerous: an over-broad stage in any repro must stay confined to the throwaway clone.

WIP

Design decisions

  • Sketch: in putRun's no-path-args branch, a non-empty ctxSub becomes the dir-form path arg (rooted /sub/), riding the EXISTING dir-stage path (stageArg dir + stageInSub for crossings) instead of bareStage — auto-pair moves under the scope dir need a check.
